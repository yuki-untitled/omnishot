画面の見た目を、深海をイメージしたデザインに刷新したリリースです。

## 新しくなったこと

- **深海をイメージした新しいデザイン:** 背景は深い紺色に、アクセントは発光するシアンとティールにそろえました。メイン画面・画像のプレビュー・接続確認・使い方ページで、同じ配色・同じ部品の見た目です。
  - 自動撮影はシアン、手動撮影・ダウンロードはスカイブルー、停止・削除・アプリ終了はコーラルの色になり、用途が見分けやすくなりました。
  - 入力欄にフォーカスしたときや、ボタンにホバーしたとき、選択した画像の縁が、淡く光ります。
- **「接続確認」ボタンの位置を変更:** 画面上部の「使い方」ボタンの左に移しました（これまでは、端末の「更新」ボタンの隣にありました）。
- **ウィンドウの最小の大きさ:** ウィンドウを、幅 940px・高さ 600px より小さくできないようにしました。撮影の設定欄が崩れずに、2行のまま表示されます。

| ファイル | 対象 |

| `OmniShot-v1.3.0-mac-arm64.zip` | Mac（Apple Silicon: M1 以降） |
| `OmniShot-v1.3.0-windows-x64.exe` | Windows 10 / 11（64ビット） |

## 注意点

- **Intel の Mac には対応していません。** Apple Silicon の Mac 専用です。
- **Windows 版は、まだ実機での動作確認をしていません。** 見た目と、ウィンドウの最小の大きさの効き方も、Windows では未確認です。不具合があれば Issue でお知らせください。
- 機能や操作は、v1.2.0 から変わっていません（接続確認ボタンの位置を除く）。
- そのほかの注意点（Mac 版の初回起動、Windows 版のネットワーク許可）は [v1.0.0 のリリースノート](https://github.com/yuki-untitled/omnishot/releases/tag/v1.0.0) と同じです。
