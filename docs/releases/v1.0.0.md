OmniShot の最初のリリースです。iPhone（iOS）と Android 端末の画面の変化を検知して、自動でスクリーンショットを撮影・保存します。

## ダウンロード

| ファイル | 対象 |
| --- | --- |
| `OmniShot-v1.0.0-mac-arm64.zip` | Mac（Apple Silicon: M1 以降） |
| `OmniShot-v1.0.0-windows-x64.exe` | Windows 10 / 11（64ビット） |

## 主な機能

- iPhone（iOS）と Android の両方を、1つのアプリで撮影
- 自動撮影（静的モード・動的モード）と手動撮影
- 撮影した画像の一覧・表示名の変更・一括ダウンロード（ZIP）・一括削除
- 撮影の開始から停止までを1つのセッションとしてまとめて表示

## Mac 版の注意点

- **Apple Silicon（M1 以降）の Mac 専用です。** Intel の Mac では起動できません。
- **Apple の署名・公証を受けていません。** 初めて開くときに macOS に止められます。
  1. zip を展開し、`OmniShot.app` を「アプリケーション」フォルダなど任意の場所に置きます。
  2. `OmniShot.app` をダブルクリックし、表示されたメッセージを閉じます。
  3. 「システム設定 > プライバシーとセキュリティ」を開き、OmniShot の「このまま開く」を押します。
  4. 「"OmniShot.app"は壊れているため開けません」と表示されて開けない場合は、ターミナルで次を実行してから開き直してください（`OmniShot.app` のある場所に合わせてパスを変えてください）。
     ```
     xattr -dr com.apple.quarantine /Applications/OmniShot.app
     ```
- 撮影した画像は、`OmniShot.app` と同じフォルダの `captures` に保存されます。
- iOS 17 以降の端末を使うための接続情報は `~/Library/Application Support/OmniShot` に保存されます。

## Windows 版の注意点

- **Windows 版は、まだ実機での動作確認をしていません。** 不具合があれば Issue でお知らせください。
- 初めて起動するときに「Windows によって PC が保護されました」と表示された場合は、「詳細情報 > 実行」を押してください。
- 「自動撮影」を初めて押したときに、ネットワークへのアクセスの許可を求められます。「パブリック ネットワーク」と「プライベート ネットワーク」の両方にチェックを付けて「許可」を押してください。
- 画面の表示に Microsoft Edge WebView2 Runtime を使います（Windows 10 21H2 以降・Windows 11 には最初から入っています）。

## 端末の準備

- **Android:** 端末の「開発者向けオプション」で「USB デバッグ」を有効にし、USB で接続します。端末に「USB デバッグを許可しますか？」と表示されたら「許可」を押してください。
- **iPhone:** USB で接続し、端末に「このコンピュータを信頼しますか？」と表示されたら「信頼」を押してください。撮影を始められない場合は、iPhone の「設定 > プライバシーとセキュリティ > デベロッパモード」をオンにしてください（動作確認に使った iPhone はオンにしています）。
