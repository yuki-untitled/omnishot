## 修正

- **アプリで、選択した画像を ZIP でダウンロードできない問題を直しました。** 「ダウンロード」を押すと保存先を選ぶ画面が開き、ZIP を保存できます。v1.0.0 では何も起きず、撮影した画像を持ち出せませんでした。

## ダウンロード

| ファイル | 対象 |
| --- | --- |
| `OmniShot-v1.0.1-mac-arm64.zip` | Mac（Apple Silicon: M1 以降） |
| `OmniShot-v1.0.1-windows-x64.exe` | Windows 10 / 11（64ビット） |

## 注意点

- Mac 版で ZIP を保存できることは確認済みです。**Windows 版は、まだ実機での動作確認をしていません。** 不具合があれば Issue でお知らせください。
- そのほかの注意点（Mac 版の初回起動、Windows 版のネットワーク許可、端末の準備）は [v1.0.0 のリリースノート](https://github.com/yuki-untitled/omnishot/releases/tag/v1.0.0) と同じです。
