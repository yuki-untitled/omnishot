## 修正

- **プレビューで画像を削除したときの表示を直しました。** 削除した画像や、壊れた画像が表示されることがありました。今後は、画面の並びで次の画像を表示します。最後の画像を削除したときは前の画像を、画像がなくなったときはプレビューを閉じます。
- **プレビューの前後の移動を、ギャラリーの画面の並びに合わせました。** これまでは、撮影が新しい順の全画像の順で移動していました。今後は、並び順の設定・セッションごとのまとまり・手動の並べ替え・端末の絞り込みが、そのまま反映されます。
- **プレビューで削除するたびに、ギャラリーの定期更新が増えていた問題を直しました。**
- **アプリの起動時・終了時に、アプリが作っていないファイルやプロセスに影響する問題を直しました。**
  - 終了時に、Windows の一時フォルダの、名前に「ios」「adb」を含むフォルダを消していたのをやめました。
  - 終了時に、Mac の `com.apple.selfidentity.plist` を消していたのをやめました。
  - 起動時に、ポート 5001 を使っているプロセスを、何であっても終了していたのをやめました。前回の OmniShot だけを終了します。別のアプリがポート 5001 を使っているときは、終了せずに、ダイアログで知らせて、起動をやめます。

## 注意点

- **Intel の Mac には対応していません。** Apple Silicon の Mac 専用です。
- **Windows 版は、まだ実機での動作確認をしていません。** 起動時のポートの整理と、終了時の後始末も、Windows では未確認です。不具合があれば Issue でお知らせください。
- そのほかの注意点（Mac 版の初回起動、Windows 版のネットワーク許可）は [v1.0.0 のリリースノート](https://github.com/yuki-untitled/omnishot/releases/tag/v1.0.0) と同じです。
