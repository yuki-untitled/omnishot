撮影情報の記録、アップデート通知、Intel の Mac への対応を加えたリリースです。

## 新機能

- **撮影情報を記録して、画像を開いたときに表示します。** 画像ごとに、撮影日時・端末名・OS と版・解像度・撮影の種類（自動／手動）を記録し、プレビューに表示します。取得できなかった項目は「不明」と表示します。画像ファイルの中身や ZIP には含めません。
- **新しい版があるときに、画面の上部でお知らせします。** 起動時に、公開されている最新の版を1回だけ確認します。新しい版があれば「ダウンロードページを開く」ボタンでリリースのページを開けます。確認できなかったときは何も表示しません。更新は自分で行います。
- **Intel の Mac 版を配布します。** これまでは Apple Silicon 専用でした。

## ダウンロード

| ファイル | 対象 |
| --- | --- |
| `OmniShot-v1.4.0-mac-arm64.zip` | Mac（Apple Silicon: M1 以降） |
| `OmniShot-v1.4.0-mac-x64.zip` | Mac（Intel） |
| `OmniShot-v1.4.0-windows-x64.exe` | Windows 10 / 11（64ビット） |

## 注意点

- **Intel の Mac 版は、まだ実機での動作確認をしていません。** 不具合があれば Issue でお知らせください。
- **Windows 版は、まだ実機での動作確認をしていません。** 不具合があれば Issue でお知らせください。
- アップデート通知は、GitHub に最新の版を問い合わせる通信を、起動時に1回行います。送るのはアプリの名前と版だけで、撮影した画像や端末の情報は送りません。
- そのほかの注意点（Mac 版の初回起動、Windows 版のネットワーク許可）は [v1.0.0 のリリースノート](https://github.com/yuki-untitled/omnishot/releases/tag/v1.0.0) と同じです。
