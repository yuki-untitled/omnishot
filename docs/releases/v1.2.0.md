初めて使う人が、iPhone・Android の準備でつまずかないようにしたリリースです。

## 新機能

- **接続確認:** 端末の「更新」ボタンの隣に「接続確認」ボタンを追加しました。押すと、接続している iPhone と Android の状態を、次の項目で自動で確認して表示します。撮影中も開けます。
  - iPhone: 接続・信頼・デベロッパモード
  - Android: 接続・USB デバッグの許可
  - すべてそろった端末には、「撮影の準備ができています」と表示されます。
- **iPhone の「デベロッパモードの項目を表示する」ボタン:** iPhone の設定に「デベロッパモード」の項目が出ないときに、ボタンで項目を表示できます（Xcode は不要です）。パスコードを設定した iPhone は、項目の表示までを行い、オンにする操作と再起動は iPhone の画面で行います。パスコードを設定していない iPhone は、そのままオンになり、iPhone が自動で再起動します（実行前に確認メッセージが表示されます）。
- **Android の「許可を要求する」ボタン:** USB デバッグの許可ダイアログが出ないときに、端末に表示し直せます。adb サーバーを起動し直すため、Android Studio など、ほかのツールの接続が一時的に切れることがあります（実行前に確認メッセージが表示されます）。
- **「使い方」ページのタブ:** 使い方・iPhone の準備・Android の準備・困ったときの4つのタブに整理しました。準備の手順は、これまでの設定ガイドの内容を、このページに移しました。

## 変更

- 画面上部の「設定ガイド」ボタンをなくしました。準備の手順は、「使い方」ページの「iPhone の準備」「Android の準備」のタブで見られます。接続確認の「手順を見る」からも、直接開けます。

## 注意点

- **Intel の Mac には対応していません。** Apple Silicon の Mac 専用です。
- **Windows 版は、まだ実機での動作確認をしていません。** 接続確認と、デベロッパモードの項目を表示するボタンも、Windows では未確認です。不具合があれば Issue でお知らせください。
- 自動撮影中は、「デベロッパモードの項目を表示する」「許可を要求する」のボタンは使えません。撮影を停止してから押してください。
- そのほかの注意点（Mac 版の初回起動、Windows 版のネットワーク許可）は [v1.0.0 のリリースノート](https://github.com/yuki-untitled/omnishot/releases/tag/v1.0.0) と同じです。
