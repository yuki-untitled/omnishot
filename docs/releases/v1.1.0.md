セッション（撮影の開始〜停止のまとまり）を、名前を付けて整理し、持ち出しやすくしたリリースです。

## 新機能

- **セッション名の変更:** ギャラリーの見出しのセッション名をクリックして、好きな名前（50文字まで）に変更できます。空にすると「セッション N」に戻ります。
- **セッション単位のダウンロード:** 見出しの「ダウンロード」ボタンで、そのセッションの画像を「セッション名.zip」にまとめて保存できます。ZIP の中のファイル名には、`001_`、`002_` のように連番が付きます。
- **セッション内の並べ替え:** セッションの中の画像を、ドラッグ＆ドロップで並べ替えられます。並べた順が、ZIP の連番に反映されます。
- **セッション単位の全選択・削除:** 見出しの「全選択」（すべて選択済みのときは「選択解除」）と「削除」で、セッションの画像をまとめて選択・削除できます。削除の前に、枚数を示す確認メッセージが表示されます。

セッション名と並べ替えた順序は、アプリを終了すると消えます（撮影した画像と同じく保存されません）。ZIP をダウンロードして持ち出してください。

## ダウンロード

| ファイル | 対象 |
| --- | --- |
| `OmniShot-v1.1.0-mac-arm64.zip` | Mac（Apple Silicon: M1 以降） |
| `OmniShot-v1.1.0-windows-x64.exe` | Windows 10 / 11（64ビット） |

## 注意点

- **Intel の Mac には対応していません。** Apple Silicon の Mac 専用です。
- **Windows 版は、まだ実機での動作確認をしていません。** 不具合があれば Issue でお知らせください。
- そのほかの注意点（Mac 版の初回起動、Windows 版のネットワーク許可、端末の準備）は [v1.0.0 のリリースノート](https://github.com/yuki-untitled/omnishot/releases/tag/v1.0.0) と同じです。
