# Web UI ギャラリー — キャプチャ画像の閲覧・管理・表示名編集

## Issue
#LOCAL-003

## 目的（Why）
自動撮影された画像は端末・撮影タイミングをまたいで大量に生成されるため、撮影のたびにファイルシステムを確認するのは非効率。アプリの画面上で一覧確認・選別・ダウンロード・削除・命名を完結させることで、撮影後の整理作業を効率化する。

## 実現内容（What）
- 撮影した画像をアプリの画面上のギャラリーでリアルタイムに一覧表示する（表示方式は [native-window.md](native-window.md) を参照）。
- 画像は全選択・個別選択ができ、選択した画像をまとめてダウンロードまたは削除できる。
- ギャラリー上でファイル名表示部分をクリックすると、任意の表示名に変更できる。
- 表示名はサーバー側に永続化され、ブラウザの `localStorage` を消去したりアプリを再起動したりしても保持される。
- 表示名を変更した画像を選択してZIPダウンロードすると、ZIP内のファイル名にも変更後の表示名が反映される。
- 表示名が未設定の画像は、従来通り元のファイル名がギャラリー表示・ダウンロードの両方で使われる。
- ギャラリーの操作案内（「選択した画像をzipファイルでダウンロードできます。ファイル名をクリックして変更できます。」）は、画面上部ではなく、ログ欄の下（ギャラリーの直前）に表示する。
- ギャラリーより上の部分（タイトルと画面上部のボタン、撮影の設定欄、ギャラリーの操作バー、ログ欄、操作案内）は、1つの枠ごと画面の上部に固定し、常に前面に表示する。枠は最初に表示された位置のまま固定し、スクロールしても位置を変えない。
- ギャラリーは、画面全体と一緒にスクロールする。スクロールしたギャラリーの画像は、固定した枠の裏に隠れていく。枠の周り（上と左右の余白、角の丸みの部分）からも、裏を通る画像は見えない。

## 受入基準
1. **一覧表示**: 撮影された画像が撮影後にギャラリーへ反映されること。
2. **全選択・個別選択**: 画像の全選択、および個別のチェックによる選択ができること。
3. **一括ダウンロード・一括削除**: 選択した画像をまとめてダウンロード、またはまとめて削除できること。
4. **表示名の永続化**: 画像の表示名を変更した後、ブラウザの `localStorage` を消去してページを再読み込みしても、変更した表示名が表示されること。
5. **表示名の永続化（再起動）**: 表示名を変更した後にアプリケーションを再起動しても、対象のキャプチャファイルが存在する限り、変更後の表示名が復元されること。
6. **ZIP内ファイル名への反映**: 表示名を変更した画像を選択してダウンロードすると、ZIP内の各ファイルのファイル名が変更後の表示名になっていること。
7. **未編集画像の回帰**: 表示名を変更していない画像は、従来通り元のファイル名でギャラリー表示・ダウンロードされること。
8. **操作案内の位置**: ギャラリーの操作案内が画面上部には表示されず、ログ欄の下（ギャラリーの直前）に表示されること。
9. **枠ごとの固定**: ギャラリーに画像が画面に収まらないほど（例: 50枚以上）ある状態で、画面を一番下までスクロールしても、タイトル・撮影の設定欄・ギャラリーの操作バー・ログ欄・操作案内が、1つの枠のまま画面の上部に表示され続け、操作できること。スクロールを始めたときも含め、枠の位置が最初の表示位置から動かないこと。
10. **枠の裏に隠れる**: 受入基準9の状態でスクロールすると、ギャラリーの画像が枠の下端から枠の裏へ隠れていき、枠の中にも、枠の上と左右の余白・角の丸みの部分にも、裏を通る画像が見えないこと。
11. **回帰**: 全選択・個別選択・一括ダウンロード・一括削除・表示名編集・プレビュー表示・設定ガイド・セッションの見出し（[session-grouping.md](session-grouping.md)）が従来どおり動作すること。プレビューと設定ガイドが、固定した枠より前面に表示されること。新しい画像が追加されたとき、スクロール位置が勝手に先頭へ戻らないこと。

## 変更理由
- issue #LOCAL-003: README.md に記載されていたWeb UIギャラリー・表示名編集の機能一覧を `docs/spec/` に分離し、README.md は概要とリンク集に整理するため作成。
- issue #LOCAL-005: ネイティブウィンドウ化に伴い、「ブラウザ上」という表現を実態に合わせて「アプリの画面上」に修正。
- issue #LOCAL-018: ギャラリーの操作案内はギャラリーに関する説明のため、ギャラリーの近くに置くよう、画面上部からログ欄の下へ移した。あわせて画面上部の表示を簡潔にした。
- issue #LOCAL-024: 画像が増えてスクロールすると、撮影の設定欄も一緒にスクロールして操作しづらいという要望を受け、ギャラリーより上の部分を1つの枠ごと画面の上部に固定し、スクロールしたギャラリーは枠の裏に隠れる形にした。当初はギャラリーだけを独立した領域でスクロールさせる形で書いたが、ユーザーの意図（枠を前面に固定し、ギャラリーは画面全体と一緒にスクロールして裏に隠れる）と違ったため書き直した。
- issue #LOCAL-024: アプリ上で、スクロールを始めたときに枠が少し上に動いてから止まることが気になるという指摘を受け、枠を最初の表示位置のまま固定することを明記した。
