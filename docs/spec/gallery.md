# Web UI ギャラリー — キャプチャ画像の閲覧・管理・表示名編集

## Issue
#LOCAL-003

## 目的（Why）
自動撮影された画像は端末・撮影タイミングをまたいで大量に生成されるため、撮影のたびにファイルシステムを確認するのは非効率。アプリの画面上で一覧確認・選別・ダウンロード・削除・命名を完結させることで、撮影後の整理作業を効率化する。

## 実現内容（What）
- 撮影した画像をアプリの画面上のギャラリーでリアルタイムに一覧表示する（表示方式は [native-window.md](native-window.md) を参照）。
- 画像は全選択・個別選択ができ、選択した画像をまとめてダウンロードまたは削除できる。
- ギャラリー上でファイル名表示部分をクリックすると、任意の表示名に変更できる。
- 表示名はサーバー側に永続化され、ブラウザの `localStorage` を消去したりアプリを再起動したりしても保持される。
- 表示名を変更した画像を選択してZIPダウンロードすると、ZIP内のファイル名にも変更後の表示名が反映される。
- 表示名が未設定の画像は、従来通り元のファイル名がギャラリー表示・ダウンロードの両方で使われる。
- ギャラリーの操作案内（「選択した画像をzipファイルでダウンロードできます。ファイル名をクリックして変更できます。」）は、画面上部ではなく、ログ欄の下（ギャラリーの直前）に表示する。

## 受入基準
1. **一覧表示**: 撮影された画像が撮影後にギャラリーへ反映されること。
2. **全選択・個別選択**: 画像の全選択、および個別のチェックによる選択ができること。
3. **一括ダウンロード・一括削除**: 選択した画像をまとめてダウンロード、またはまとめて削除できること。
4. **表示名の永続化**: 画像の表示名を変更した後、ブラウザの `localStorage` を消去してページを再読み込みしても、変更した表示名が表示されること。
5. **表示名の永続化（再起動）**: 表示名を変更した後にアプリケーションを再起動しても、対象のキャプチャファイルが存在する限り、変更後の表示名が復元されること。
6. **ZIP内ファイル名への反映**: 表示名を変更した画像を選択してダウンロードすると、ZIP内の各ファイルのファイル名が変更後の表示名になっていること。
7. **未編集画像の回帰**: 表示名を変更していない画像は、従来通り元のファイル名でギャラリー表示・ダウンロードされること。
8. **操作案内の位置**: ギャラリーの操作案内が画面上部には表示されず、ログ欄の下（ギャラリーの直前）に表示されること。
