# 撮影端末の選択 — 複数の端末が接続されている状態で、撮影する端末を選べる

## Issue
#LOCAL-014

## 目的（Why）
現在は、接続中の端末のうち最初に見つかった1台（Android が優先）が自動で使われ、ユーザーは撮影する端末を選べない。複数の端末（例: iPhone を2台、または iPhone と Android）を接続している状態では、意図しない端末が撮影されてしまう。撮影する端末をユーザーが選べるようにすることで、複数端末の環境でも狙った端末を撮影できるようにする。

## 実現内容（What）
- 撮影の設定欄に、接続中の端末を選ぶプルダウンと、端末一覧を再検出する更新ボタンを置く。
- 撮影の設定欄は2行で構成する。
  - 1行目（撮影の条件）: チェック間隔、静止待ち時間（動的モードでは判定回数）、モード。
  - 2行目（撮影の対象と操作）: 端末、更新ボタン、自動撮影開始ボタン、停止ボタン、ステータス表示。
  - 2行は1つのパネルにまとまり、パネルの左端と右端が2行でそろう。1行目の3項目は同じ幅で並ぶ。2行目は、左側に端末のプルダウンと更新ボタン、右側に自動撮影開始・停止・ステータスを寄せて配置し、端末のプルダウンは、1行目の1項目と同じ幅を上限とする（狭い画面でも読める幅を下限にする）。自動撮影開始・停止・ステータスは、1つのまとまりとして扱い、行が折り返す場合も一緒に右端へ寄る。
  - 更新ボタンと自動撮影開始ボタンの間は、他のボタン間（自動撮影開始と停止の間など）より広く空け、「端末の選択」と「撮影の操作」を視覚的に区切る。
  - 各項目は、項目名を入力欄の上に小さく表示する。入力欄・プルダウン・ボタンの高さは同じにする。
  - ステータスは、状態を示す丸印とともに表示する（撮影中は緑、停止中は灰色）。
- 一覧に載せるのは、USB ケーブルで接続されている端末（iOS / Android）のみ。Wi-Fi 経由でだけ見える端末（iPhone の「Wi-Fi 経由で同期」、Android のワイヤレスデバッグなど）は載せない。
- プルダウンの各項目は「OS の種別・端末名・識別子の末尾6文字」の形式で表示する（例: `iOS・Eidome's iPhone・8BA01E`）。項目を選んで閉じた状態でも OS が分かるよう、OS の種別は項目ごとに表示する。端末名が取得できない場合（この Mac が信頼していない端末など）は、端末名を省き「OS の種別・識別子の末尾6文字」で表示する。識別子は、同じ機種を複数台接続していても区別できるよう、機種ごとに共通になりやすい先頭ではなく末尾を使う。
- 端末が2台以上あるとき、プルダウンの項目は OS ごとにまとめ、「-- iOS --」「-- Android --」の見出しの下に並べる。見出しの順は iOS、Android。端末が無い OS の見出しは表示しない。端末が1台のときは見出しを表示しない。
- 撮影するのは、プルダウンで選んだ1台のみ。複数台の同時撮影は行わない。
- 端末の一覧は、アプリの起動時と、更新ボタンを押したときに検出する。それ以外のタイミングでは自動で再検出しない。
- 選択の初期状態は、検出された端末の数で決まる。
  - 0台: プルダウンに「端末が見つかりません」と表示する。
  - 1台: その端末が自動で選ばれる。
  - 2台以上: 未選択で、ユーザーが選ぶ。
- 2台以上で未選択のまま「撮影開始」を押した場合は、「撮影する端末を選択してください」と表示し、撮影を開始しない。
- 撮影中は、プルダウンと更新ボタンを操作できない。撮影を停止すると操作できるようになる。
- 更新ボタンで一覧を再検出したとき、選択中の端末が一覧に無ければ選択を解除する。一覧にあれば、選択を維持する。
- 撮影開始の時点で、選択した端末が接続されていない場合は、「選択した端末が接続されていません」と表示し、撮影を開始しない。
- 選択した端末の情報は、アプリを終了すると残らない。ファイルやブラウザの保存領域には保存しない。
- 保存されるスクリーンショットのファイル名、および撮影のタイミング（静的モード・動的モード）は、従来どおり。

## 受入基準
1. **一覧の表示**: iPhone を2台接続して起動すると、プルダウンに2台が、それぞれ「iOS・端末名・識別子の末尾6文字」の形式で表示されること。同じ機種の2台でも、表示が異なること。端末名が取得できない端末は「iOS・識別子の末尾6文字」で表示されること。
2. **OS ごとのまとまり**: iPhone と Android を1台ずつ接続すると、「-- iOS --」の下に iPhone が、「-- Android --」の下に Android が表示されること。Android が無いときは「-- Android --」が表示されないこと。端末が1台のときは、見出しが表示されないこと。
3. **USB 接続のみを一覧に載せる**: USB では接続されておらず Wi-Fi 経由でだけ見える端末（iPhone の「Wi-Fi 経由で同期」が有効な端末など）は、一覧に表示されないこと。USB ケーブルを接続すると表示されること。同じ端末が USB と Wi-Fi の両方で見えている場合（Wi-Fi 経由の同期が有効な iPhone を USB で接続した場合など）は、USB で接続されているとして、一覧に1件だけ表示されること。
4. **1台のとき**: 端末を1台だけ接続して起動すると、その端末が選択済みで表示され、端末を選ばずに「撮影開始」で撮影が始まること。
5. **0台のとき**: 端末が接続されていない状態で起動すると、プルダウンに「端末が見つかりません」と表示されること。この状態で「撮影開始」を押すと、従来どおり「デバイスが検出されませんでした」のメッセージが表示され、撮影が始まらないこと。
6. **選んだ端末だけを撮影**: 2台以上を接続し、片方を選んで撮影を開始すると、選んだ端末の画面だけが撮影され、もう一方の端末の画面は保存されないこと。プルダウンで別の端末を選び直した場合も、その端末だけが撮影されること。
7. **未選択での開始の拒否**: 2台以上を接続して未選択のまま「撮影開始」を押すと、「撮影する端末を選択してください」と表示され、撮影が始まらないこと。
8. **撮影中の操作制限**: 撮影中は、プルダウンと更新ボタンが操作できないこと。撮影を停止すると、操作できるようになること。
9. **更新ボタン**: 端末を抜き差しして更新ボタンを押すと、一覧が現在の接続状態に更新されること。選択中の端末を抜いて更新すると選択が解除され、選択中の端末が接続されたままなら選択が維持されること。
10. **選択後に切断された場合**: 端末を選んだ後にその端末を抜き、更新せずに「撮影開始」を押すと、「選択した端末が接続されていません」と表示され、撮影が始まらないこと。
11. **保存データを残さない**: アプリを終了して再起動すると、選択が引き継がれないこと（1台なら自動選択、2台以上なら未選択に戻る）。選択に関するファイルやブラウザの保存データが作られないこと。
12. **設定欄の配置**: 撮影の設定欄の1行目に「チェック間隔」「静止待ち時間（動的モードでは判定回数）」「モード」が、2行目に「端末」「更新」「自動撮影開始」「停止」「ステータス」が、この順で表示されること。モードを切り替えても、行の構成が変わらないこと。
13. **設定欄の見た目**: 画面幅1000px以上で、1行目と2行目の左端・右端が同じ位置にそろうこと。1行目の3項目の幅が等しいこと。入力欄・プルダウン・ボタンの高さが同じであること。ステータスの丸印が、停止中は灰色、撮影中は緑であること。更新ボタンと自動撮影開始ボタンの間隔が、自動撮影開始ボタンと停止ボタンの間隔より広いこと。画面幅1000px以上で、端末のプルダウンの幅が1行目の1項目の幅以下であること。自動撮影開始・停止・ステータスが、行の右端に寄っていること（ステータスの右端がパネルの内側の右端と一致すること）。画面幅700pxでも、項目名や項目が折り返して崩れないこと。
14. **回帰（撮影機能）**: 撮影の開始・停止、静的モード・動的モードの撮影タイミング、保存されるファイル名の形式が、従来どおり動作すること（[screenshot-capture.md](screenshot-capture.md) の受入基準）。
15. **回帰（ギャラリー）**: 撮影された画像が、従来どおりギャラリーに表示されること（[gallery.md](gallery.md)）。

## 制約・関連機能
- 撮影の仕様は [screenshot-capture.md](screenshot-capture.md) を参照。本仕様は、その「1つのアプリで iPhone と Android の両方を接続してキャプチャできる」に、端末の選択を加えるもの。
- 画面は [native-window.md](native-window.md) のネイティブウィンドウ内に表示される。ウィンドウ終了時に保存データを残さない方針（[native-window.md](native-window.md)、[LOCAL-013](bugs/LOCAL-013_設定ガイドの次回から表示しないを廃止し起動時の自動表示をやめる.md)）に従う。
- 現在の実装は、Wi-Fi 経由でだけ見える iOS 端末も「iOS 端末が接続されている」と判定し、ケーブルを接続していないのに撮影開始が進む。本仕様の「USB 接続のみを一覧に載せる」により、この判定も改める。
- 端末の検出には数秒かかる場合があるため、一覧は自動で繰り返し更新しない。
- 複数台の同時撮影、および端末ごとの撮影設定の使い分けは、本仕様の対象外。

## 変更理由
- issue #LOCAL-014: 複数の端末が接続されている状態で、撮影する端末を選べるようにしてほしいという要望を受けて新規作成。同時に撮影するのは1台のみ、選択 UI は撮影設定欄のプルダウンと更新ボタン、一覧の更新は起動時と更新ボタン押下時のみ、と合意した。
- issue #LOCAL-014: 開発機で、Wi-Fi 経由でだけ見える iPhone が「接続中」と判定されることを確認したため、一覧に載せる端末を USB 接続のみとした（ユーザー合意）。
- issue #LOCAL-014: 端末名が取得できない場合の表示を、「識別子のみ」から「OS の種別と識別子」に明確化した（OS の種別も判別できるようにするため）。
- issue #LOCAL-014: 実装完了。端末の一覧・選択・開始の判定・画面の操作を、コマンド出力を模した確認と、この Mac の実際の接続状態（USB 接続の iPad が1台）で検証済み。複数台を同時に接続した実機での撮影、端末名の表示（信頼済みの端末）、Windows での動作は、今後実機で確認する。
- issue #LOCAL-014: 撮影の設定欄を、撮影の条件（1行目）と、撮影の対象・操作（2行目）の2行構成にするレイアウトの要望を受けて、配置を仕様に追記。
- issue #LOCAL-014: 設定欄の2行レイアウトを実装。1280px幅と700px幅で実際に描画して、1行目・2行目の構成を確認済み（700px幅で「端末:」が折り返す点は修正済み）。動的モードでの判定回数の表示切り替えは、要素の構成のみ確認し、実画面での目視は今後実施。
- issue #LOCAL-014: 2行の設定欄の見た目のバランスが悪いという指摘を受け、パネルにまとめて左右の端をそろえ、項目名を入力欄の上に置き、ステータスを丸印つきにするレイアウトを仕様に追記。
- issue #LOCAL-014: 設定欄のレイアウト調整を実装。実際に描画して、画面幅1280・1000・700・420pxで、2行の左右端が同じ位置になること、1行目の3項目が同じ幅になること、入力欄・プルダウン・ボタン・ステータスの高さが36pxでそろうこと、ステータスの丸印が停止中は灰色・撮影中は緑になることを計測で確認済み。動的モードでも行の構成が変わらないことも確認済み。ネイティブウィンドウ上での目視確認は今後実施。
- issue #LOCAL-014: 端末の選択（端末・更新）と、撮影の操作（自動撮影開始・停止・ステータス）の区切りが分かりにくいという指摘を受け、更新ボタンと自動撮影開始ボタンの間隔を広げる指定を追記。
- issue #LOCAL-014: 端末のプルダウンが横に長すぎるという指摘を受け、端末のプルダウンに最大幅を設け、撮影の操作（自動撮影開始・停止・ステータス）を右端に寄せる配置に変更。
- issue #LOCAL-014: 端末のプルダウンの最大幅と、撮影の操作の右寄せを実装。画面幅1280・1000・700・420pxで計測し、端末の幅が1行目の1項目の幅と一致（1000px以上）、ステータスの右端がパネルの右端と一致、更新と自動撮影開始の間隔が広いこと、横スクロールが出ないことを確認済み。
- issue #LOCAL-014: 実機で、Wi-Fi 経由の同期が有効な iPhone を USB で接続しても一覧に表示されない不具合を確認した。同じ端末が USB と Wi-Fi の両方のエントリで見えるため、USB のエントリが1つでもあれば USB とみなし、一覧には1件だけ載せると明記した。
- issue #LOCAL-014: iOS と Android を同時に接続した場合に見つけやすいよう、プルダウンを OS ごとにまとめる表示にした（ユーザー提案）。あわせて、識別子の先頭8文字は機種ごとに共通になりやすく、同じ機種の複数台を区別できないため、末尾6文字に変更した。
- issue #LOCAL-014: OS ごとのまとまりと、識別子の末尾6文字の表示を実装。実際の Chrome で、同じ機種（識別子の先頭が同じ）の iPhone 2台と Android 1台の表示、見出しの構造を確認し、画面の動作テストも通過。1台のとき・端末が無い OS の見出しを出さないことも確認済み。ネイティブウィンドウ上でのプルダウンの見た目は今後実施。
