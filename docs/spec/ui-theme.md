# 画面のテーマ（深海） — 全画面の配色と部品の見た目を、深海をイメージしたデザインにそろえる

## Issue
#LOCAL-040

## 目的（Why）
現在の画面は、灰色の背景に、緑・青・赤の標準的な色のボタンを使っており、アプリとしての印象が薄い。色の指定が画面ごと・部品ごとに直接書かれていて、配色をそろえて変えることも難しい。

「深海」をイメージした、近未来的でスマートな見た目に整えることで、アプリの印象を高める。あわせて、画面の色の定義を1か所にまとめ、以後の調整を容易にする。

## 実現内容（What）
### 全体の方針
- 深い紺色から黒に近い背景に、発光するシアンとティールをアクセントにする。水深の深い場所で、生き物や計器が淡く光っているイメージ。
- 演出は控えめにする。光る表現は、色の変化・細い縁・淡い影に限る。ステータス表示の脈動などの、動き続ける表現は入れない。状態が変わる動き（ホバーなど）は、0.3秒以内とする。
- 主役はスクリーンショットの画像とする。ギャラリーの画像とカードの見やすさを、装飾で損なわない。
- 対象の画面は、メイン画面（上部の固定枠・ギャラリー）、画像のプレビュー、接続確認、使い方ページのすべて。すべて同じ配色・同じ部品の見た目にする。
- フォントは、従来どおりシステムの標準のフォントを使う。外部から取得する資源（フォントなど）は使わない。

### 配色
色は、用途ごとに次の値とする。

| 用途 | 色 |
| --- | --- |
| ページの背景（最深部） | `#050d16` |
| 枠・パネル・モーダルの面 | `#0a1b2b` |
| 入力欄・カードの面 | `#0f2638` |
| 境界線（通常） | `#17384f` |
| 境界線（強調・フォーカス中の縁の基本） | `#24506c` |
| 文字 | `#d6e9f2` |
| 補助の文字（項目名・説明） | `#7f9fb3` |
| アクセント（シアン。主要な操作・選択・撮影中） | `#22d3ee` |
| アクセント2（ティール。補助の強調） | `#2dd4bf` |
| 情報（スカイブルー。手動撮影・ダウンロード・並べ替えの目印） | `#38bdf8` |
| 危険（コーラル。削除・停止・終了） | `#d93a4c` |
| アクセント・情報の色のボタン上の文字 | `#03202b` |
| 危険の色のボタン上の文字 | `#ffffff` |
| 上部の固定枠のグラデーションの上端 | `#0d2438` |
| 危険（コーラル）のホバー | `#c22f41` |
| ログ欄の背景 | `#020a10` |
| アクセントの淡い光（縁の外側の光） | アクセントの色の透明度 35% |
| アクセントの淡い面 | アクセントの色の透明度 8% |

- ページの背景は、単色（グラデーションなし）とする。上部に固定した枠の裏を通る画像を隠す仕組み（[gallery.md](gallery.md)）が、ページの背景と同じ色で塞ぐため。
- 上部の固定枠の面には、上から下へ、`#0d2438` から `#0a1b2b` になる、ごく淡いグラデーションを付ける。

### 部品の見た目
- **主要ボタン**（自動撮影・接続確認の主要な操作・閉じる）: アクセント（シアン）の背景に、暗い文字。ホバーで少し明るくなる。
- **停止・削除・アプリ終了のボタン**: 危険（コーラル）の背景に、白い文字。
- **手動撮影・全選択・ダウンロードのボタン**: 情報（スカイブルー）の背景に、暗い文字。
- **補助のボタン**（更新・接続確認・使い方・選択解除・各種の小さなボタン）: 面の色に、境界線、文字色は通常の文字。ホバーで境界線がアクセントの色になり、淡く光る。
- **入力欄・プルダウン**: 入力欄の面に境界線。フォーカスすると、境界線がアクセントの色になり、淡く光る。
- **選択したカード**: 縁がアクセントの色になり、淡く光る。カードの面は入力欄の面の色。
- **ステータス表示**: 撮影中は丸印と文字がアクセントの色、停止中は補助の文字の色にする。
- **手動撮影のバッジ**: 情報（スカイブルー）の色。
- **並べ替え中のドロップ位置の線**: 情報（スカイブルー）の色。
- **ログ欄**: 暗い背景に、ティール系の明るい文字（緑一色の従来の見た目ではなく、配色に合わせる）。等幅フォントは変えない。
- **タブ**（使い方ページ）: 選択中のタブはアクセントの色、それ以外は面の色。
- **モーダル**（プレビュー・接続確認）: 背景の覆いは、ページの背景色を透過させた暗い色。接続確認の面は、枠・パネルの面の色に、細い縁と淡い影を付ける。
- **状態の表示の色**（接続確認の ✅・⚠️・❔ の絵文字は、そのまま使う）: 実行結果のメッセージは、補助の面にアクセント2の縁。

### 色の定義
- 画面の色は、1か所（共通の変数）にまとめて定義し、各部品はそこから参照する。その値を変えると、すべての画面の配色が変わる。
- 上記のほかに、色を直接書かない（[gallery.md](gallery.md) の固定枠の覆いの色も、ページの背景の色の定義を参照する）。

### 変更しないもの
- 画面の構成・部品の配置・文言・操作は、変えない。見た目（色・縁・影・角丸）だけを変える。
- ギャラリーの画像とカードには、背景をぼかす効果を使わない（画像が数百枚並んでも軽く動かすため）。

## 受入基準
1. **配色の統一**: メイン画面・画像のプレビュー・接続確認・使い方ページの背景・面・文字・ボタンの色が、上記の配色になっていること。灰色（旧配色の `#121212`、`#1a1a1a`、`#252525` など）や、緑（`#2ecc71`）、青（`#3498db`）の旧配色が、画面に残っていないこと。
2. **読みやすさ**: 文字と背景のコントラスト比が、通常の文字は 4.5 対 1 以上、補助の文字は 4.5 対 1 以上であること。ボタンの文字と背景も 4.5 対 1 以上であること。
3. **主要な部品の色**: 自動撮影ボタンがシアン、停止・削除・アプリ終了ボタンがコーラル、手動撮影・全選択・ダウンロードボタンがスカイブルーであること。
4. **状態の色**: 撮影中はステータスの丸印と文字がシアン、停止中は補助の文字の色になること。選択したカードの縁がシアンになること。
5. **フォーカスとホバー**: 入力欄・プルダウンにフォーカスすると縁がシアンになり、補助のボタンにホバーすると縁がシアンになること。ホバーの色の変化が 0.3 秒以内に終わること。
6. **固定枠の回帰**: 画像が画面に収まらないほど（例: 50枚以上）あるとき、スクロールしても、上部の固定枠が動かず、枠の周り（上と左右の余白、角の丸みの部分）から、裏を通る画像が見えないこと（[gallery.md](gallery.md) の受入基準9・10）。
7. **色の定義**: 配色の変数の値を1か所変えると、メイン画面・プレビュー・接続確認・使い方ページの、対応する色がすべて変わること。画面のコード（スタイルシート、画面の HTML、画面の JavaScript）に、配色の変数以外の色が直接書かれていないこと（モーダルの背景の覆いと、枠の影の、透明度つきの色を除く）。
8. **画像の見やすさと軽さ**: ギャラリーのカードに、背景をぼかす効果を使っていないこと。100枚以上の画像を並べた状態で、スクロールが従来と同じ程度に滑らかであること。
9. **回帰**: 端末の選択・撮影・ギャラリーの操作・接続確認・セッションの操作・使い方ページのタブが、従来どおり動作すること。画面の構成・文言が変わっていないこと。

## 制約・関連機能
- 上部の固定枠と、その裏に隠れるギャラリーの仕様は [gallery.md](gallery.md) を参照。固定枠の覆いの色は、ページの背景の色と同じにする必要がある。
- 撮影の設定欄の構成は [device-selection.md](device-selection.md) を参照。本仕様は、その色・縁・影だけを変える。
- 接続確認・使い方ページの構成は [setup-guide.md](setup-guide.md) を参照。
- WebKit（Mac）と WebView2（Windows）の両方で表示できる、標準の CSS だけを使う。Windows での見た目は、実機で未確認。
- 外部から取得する資源（Web フォント・画像など）は使わない。アプリは、ネットワークに接続できない環境でも同じ見た目で動く。

## 変更理由
- issue #LOCAL-040: アプリの印象を高めるため、深海をイメージした、近未来的でスマートな見た目にしたいという要望を受けて新規作成。演出は控えめにすること、全画面を一度にそろえること、アクセントはシアンとティールにすることを、ユーザーと決めた。
