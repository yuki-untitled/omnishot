# 撮影セッションのグルーピング — 撮影の開始〜停止を1セッションとしてギャラリーで区切る

## Issue
#LOCAL-016、#LOCAL-034、#LOCAL-035

## 目的（Why）
現状のギャラリーは、撮影された画像がすべて単一の一覧に時系列で積み上がる。1回のアプリ起動中に複数の操作フロー（例: ログイン手順、設定変更手順など、別々の一連の操作）を順に撮影すると、どこからどこまでが1つの操作のまとまりかがギャラリー上で分からず、後から画像を選び出す・整理する作業が煩雑になる。自動撮影の開始〜停止を1つのセッションとしてギャラリー上で区切り表示することで、複数の操作フローを1回のアプリ起動でも整理しやすくする。

さらに、セッションに番号しか付かないと、後から「どの操作フローか」を見分けにくく、整理した結果を渡すときも画像を選び直す手間がかかる。セッションに名前を付け、セッション単位で ZIP にして持ち出し、セッション内の画像を意図した順に並べられるようにすることで、撮影結果を操作フローごとに整えて共有しやすくする（#LOCAL-034）。

また、不要になった操作フロー（撮り直した手順など）の画像を、ギャラリー全体から1枚ずつ、または全選択して選び直すのは手間がかかる。セッション単位で全選択と削除ができるようにして、撮り直しや整理を素早く行えるようにする（#LOCAL-035）。

## 実現内容（What）
- 自動撮影の「開始」ボタンを押すたびに新しいセッションが始まり、「停止」ボタンでそのセッションが終わる。
- セッション番号は、アプリ起動後に自動撮影を開始した順に 1, 2, 3... と振る。
- ギャラリーは、セッションに属する画像をまとめ、その末尾に「未分類」の画像をまとめて表示する。セッションの区切りには見出しを挿入し、見出しには、セッション番号・開始日時・そのセッションで撮影された画像の枚数を表示する。セッション同士の順序、および各セッション・未分類グループ内の画像の順序は、ギャラリーの並び順設定（新しい順・古い順）に従う。
- 自動撮影が「撮影中」の間に [manual-capture.md](manual-capture.md) の手動撮影で保存した画像は、そのセッションに含め、見出しの枚数にも数える。
- 自動撮影を一度も開始していない状態、または自動撮影を停止した後で次のセッションを開始する前に手動撮影で保存した画像は、「未分類」として扱う。「未分類」の画像は、実際に撮影された時刻に関わらず、すべてのセッションより後ろ（一覧の末尾）に、1つの見出しへまとめて表示する。自動撮影中に確認したいセッションの画像が、単発の未分類画像によって埋もれないようにするため。
- アプリ再起動後にギャラリーへ表示される、前回起動時までに保存された既存の画像は、セッション情報を持たないため「未分類」として、同様に一覧の末尾に表示する。
- セッションの区切り（見出し・番号）は永続化しない。アプリを終了すると失われ、次回起動時はセッション番号が1から振り直される。画像ファイル自体は、従来通り [gallery.md](gallery.md) の管理下に残る。
- 全選択・個別選択・一括ダウンロード・一括削除・表示名編集は、従来通りギャラリー全体（セッションをまたいで）に対して機能する。セッション単位の一括ダウンロードは、下の「セッション単位のダウンロード」で定める。セッション単位の全選択・削除は、下の「セッション単位の全選択・削除」で定める。
- ユーザーが並べ替えをしない限り、セッション・未分類それぞれのグループの中では、画像本体の並び順を変更しない。

### セッション名の変更（#LOCAL-034）
- セッションの見出しのセッション名の部分をクリックすると、セッション名を自由に変更できる。名前は1〜50文字で、前後の空白は取り除く。
- セッション名が未設定のセッションは、従来通り「セッション N」（N はセッション番号）と表示する。名前を空にして確定すると、未設定に戻る。
- 名前を付けたセッションの見出しには、セッション名・開始日時・撮影枚数を表示する（セッション番号は表示しない）。
- 同じ名前を複数のセッションに付けてもよい。
- 「未分類」の名前は変更できない。
- セッション名は、セッションの区切りと同じく永続化しない。アプリを終了すると失われる。

### セッション単位のダウンロード（#LOCAL-034）
- 各セッションの見出しの横にダウンロードボタンを置く。押すと、そのセッションの画像すべてを1つの ZIP にまとめ、保存先を選んで保存できる。
- ZIP のファイル名は「セッション名.zip」とする。名前が未設定のセッションは「セッションN.zip」（N はセッション番号）とする。ファイル名に使えない文字（`/ \ : * ? " < > |`）は `_` に置き換える。
- 「未分類」の見出しにもダウンロードボタンを置き、ZIP のファイル名は「未分類.zip」とする。
- ZIP の中のファイル名は、[gallery.md](gallery.md) と同じく表示名（未設定なら元のファイル名）を使い、その前に3桁の連番と `_` を付ける（例: `001_ログイン画面.png`）。連番は 001 から始め、セッションの画像の並び順（下の「セッション内の並べ替え」）に振る。並べ替えをしていないセッションは、撮影の古い順に振る。
- 選択状態（チェック）はセッション単位のダウンロードに影響せず、ダウンロードによって選択状態も変わらない。
- 画像が0枚のセッションのダウンロードボタンは押せない。

### セッション単位の全選択・削除（#LOCAL-035）
- 各セッションと「未分類」の見出しに、「全選択」ボタンと「削除」ボタンを置く（ダウンロードボタンの隣）。
- 「全選択」を押すと、そのセッションの画像すべてにチェックが入る。そのセッションの画像がすべてチェック済みのときは、ボタンの表示が「選択解除」に変わり、押すとそのセッションの画像のチェックがすべて外れる。ほかのセッションの選択状態は変わらない。
- 「削除」を押すと、「セッション名」の N 枚の画像を削除するかを確認するメッセージが表示され、確定するとそのセッションの画像がすべて削除される。キャンセルすると何も削除されない。チェックの有無に関わらず、そのセッションの画像すべてが対象になる。
- 全選択・削除の対象は、ギャラリーに表示されているそのセッションの画像とする。ギャラリーの端末フィルタ（iOS・Android の絞り込み）で隠れている画像は、対象に含めない。確認メッセージの枚数も、対象の枚数とする。
- 削除した画像の表示名・セッションへの所属は、[gallery.md](gallery.md) の一括削除と同じく残さない。画像がなくなったセッションは、見出しごとギャラリーから消える。消えたセッションの番号は、ほかのセッションに使い回さない。
- 自動撮影が「撮影中」のセッションも削除できる。削除した後に撮影された画像は、引き続きそのセッションに含める。
- 選択した画像を削除する従来の操作（画面上部の「選択した画像を削除」）は、そのまま使える。

### セッション内の並べ替え（#LOCAL-034）
- 各セッションの画像は、ドラッグ＆ドロップで同じセッションの中の好きな位置へ移動できる。別のセッションや「未分類」へは移動できない。「未分類」の画像は並べ替えの対象外とする。
- 並べ替えた順序は、そのセッションの並び順としてギャラリーに表示し、セッション単位のダウンロードの連番（上記）に反映する。
- 並べ替えたセッションに、その後で新しい画像（自動撮影・手動撮影）が保存された場合は、そのセッションの末尾に追加する。
- ギャラリーの並び順設定（新しい順・古い順）を変更すると、すべてのセッションの手動の並べ替えは破棄され、設定に従う並びに戻る。
- 並べ替えた順序は永続化しない。アプリを終了すると失われる。画像ファイル自体の名前・保存場所は、並べ替えでは変わらない。

## 受入基準
1. **開始のたびに新セッション**: 自動撮影を「開始」→「停止」→再度「開始」すると、ギャラリーに2つのセッション見出しが表示され、それぞれの見出しの下に、そのセッション中に撮影された画像だけが表示されること。
2. **見出しの内容**: 各セッションの見出しに、セッション番号・開始日時・撮影枚数が表示され、枚数がそのセッションで実際に保存された画像数（自動撮影＋セッション中の手動撮影の合計）と一致すること。
3. **セッション外の手動撮影**: 自動撮影が停止中の間に手動撮影で画像を保存すると、その画像が「未分類」として、すべてのセッションより後ろ（一覧の末尾）に表示されること。
4. **起動直後の手動撮影**: 自動撮影を一度も開始していない状態で手動撮影を行うと、その画像が「未分類」として一覧の末尾に表示されること。
5. **既存画像の扱い**: アプリを再起動した後、前回起動時に保存済みだった画像がギャラリーに表示される際、「未分類」として一覧の末尾に表示されること。
6. **番号の振り直し**: アプリを再起動して自動撮影を新たに開始すると、セッション番号が1から振り直されること。
7. **グループ内の時系列順の維持**: セッション見出しが挿入されていても、並べ替えをしていない各セッション・未分類それぞれのグループ内での画像本体の並び順が撮影時刻順のまま変わらないこと。
8. **未分類のまとめ**: 複数回に分けて（例: セッションとセッションの合間に複数回）未分類の画像が生まれた場合も、ギャラリーでは1つの「未分類」見出しの下にまとめて表示されること（見出しが複数回出ないこと）。
9. **一括操作の回帰**: セッション見出しがある状態でも、全選択・個別選択・一括ダウンロード・一括削除・表示名編集が、セッションをまたいで従来通り動作すること（[gallery.md](gallery.md) の受入基準）。
10. **非永続化**: セッションの区切り表示がある状態でアプリを終了し再起動すると、以前のセッションの区切り・番号・名前・並べ替えた順序が再現されないこと（画像ファイル自体は残ること）。
11. **セッション名の変更**: セッションの見出しのセッション名をクリックして「ログイン手順」と入力して確定すると、見出しが「ログイン手順」に変わり、セッション番号が表示されず、開始日時・枚数は変わらないこと。空にして確定すると「セッション N」の表示に戻ること。51文字以上は入力できない、または確定時に50文字に収まらない名前が保存されないこと。「未分類」の名前は変更できないこと。
12. **セッション名の維持**: 名前を付けたセッションで撮影を続けても（そのセッションが撮影中でも停止後でも）、名前が変わらないこと。ギャラリーの再読み込み（一定間隔の更新）で、名前の編集中の入力が失われないこと。
13. **セッション単位のダウンロード**: 画像が3枚あるセッション「ログイン手順」の見出しのダウンロードボタンを押すと、保存先を選ぶダイアログが開き、「ログイン手順.zip」の名前で保存でき、ZIP の中にそのセッションの3枚だけが含まれること。他のセッション・未分類の画像は含まれないこと。
14. **ZIP名と未設定・未分類**: 名前が未設定のセッション1をダウンロードすると「セッション1.zip」、未分類をダウンロードすると「未分類.zip」になること。セッション名に `/` を含む場合、その文字が `_` に置き換わったファイル名になること。
15. **ZIP内の連番**: 受入基準13のZIPの中のファイル名が、`001_`・`002_`・`003_` で始まり、表示名を設定した画像は `001_表示名` の形になること。並べ替えをしていないセッションでは、撮影の古い順に連番が振られること。
16. **並べ替え**: セッション内の画像をドラッグ＆ドロップで別の位置へ移動すると、その並びでギャラリーに表示され、更新（一定間隔の再読み込み）の後も維持されること。別のセッションや「未分類」の領域へはドロップしても移動しないこと。
17. **並べ替えのZIP反映**: 並べ替えたセッションをダウンロードすると、ZIP内の連番が、画面上の並びどおりに振られていること。
18. **並べ替え後の追加と並び順設定**: 並べ替えたセッションに新しい画像が保存されると、そのセッションの末尾に表示されること。ギャラリーの並び順設定を変更すると、並べ替えが破棄され、設定に従う並びに戻ること。
19. **ダウンロードの回帰**: 選択した画像の一括ダウンロード（[gallery.md](gallery.md)）が従来通り動作し、ZIP 内のファイル名に連番が付かないこと。セッション単位のダウンロードで、チェックの選択状態が変わらないこと。ビルドしたアプリでも、保存先を選ぶダイアログが開いて ZIP を保存できること（[LOCAL-033](bugs/LOCAL-033_アプリ化するとスクリーンショットをダウンロードできない.md)）。
20. **セッション単位の全選択**: セッションが2つある状態で、1つ目の見出しの「全選択」を押すと、1つ目のセッションの画像すべてにチェックが入り、2つ目のセッションの選択状態は変わらないこと。ギャラリー上部の選択数の表示が、選択した枚数に更新されること。
21. **選択解除の切り替え**: セッションの画像がすべてチェック済みのとき、そのセッションのボタンが「選択解除」と表示され、押すとそのセッションの画像のチェックだけがすべて外れること。1枚でもチェックが外れると、ボタンが「全選択」に戻ること。
22. **セッション単位の削除**: 3枚のセッション「ログイン手順」の見出しの「削除」を押すと、「ログイン手順」の3枚の画像を削除するかを確認するメッセージが表示されること。確定すると、そのセッションの3枚だけが削除され、見出しも消えること。ほかのセッション・未分類の画像は残ること。キャンセルすると何も削除されないこと。チェックを入れていない状態でも削除できること。
23. **絞り込み中の対象**: 端末フィルタで一部の画像が隠れている状態で、セッションの「全選択」「削除」を押すと、表示されている画像だけが対象になり、確認メッセージの枚数も表示されている枚数と一致すること。隠れている画像は残ること。
24. **削除の後始末**: セッション単位で削除した画像の表示名が残らず、削除したセッションの見出しが再び表示されないこと。撮影中のセッションを削除した後に撮影された画像は、そのセッションの見出しの下に表示されること。

## 制約・関連機能
- 手動撮影の仕様は [manual-capture.md](manual-capture.md) を参照。セッション中に行った手動撮影の扱いは本仕様で定める。
- 撮影対象の端末選択は [device-selection.md](device-selection.md) を参照。本仕様は端末の選択状態には関与しない。
- 画像の一覧・一括操作・表示名編集の基本仕様は [gallery.md](gallery.md) を参照。本仕様は、その一覧に見出しによる区切りを追加するものであり、一覧・選択・操作の対象範囲は変更しない。
- ウィンドウ終了時に保存データを残さない方針（[native-window.md](native-window.md)）に合わせ、セッションの区切り情報も永続化しない。
- 複数端末の同時撮影時のセッション扱い・セッション名や並べ替えた順序の永続化・「未分類」の並べ替えは、本仕様の対象外。
- セッション単位のダウンロードは、アプリのウィンドウでのダウンロード許可（[LOCAL-033](bugs/LOCAL-033_アプリ化するとスクリーンショットをダウンロードできない.md)）を前提とする。

## 変更理由
- issue #LOCAL-016: 1回のアプリ起動中に複数の操作フローを撮影する際、ギャラリー上でどこからどこまでが1つのまとまりか分かりにくいという課題を受けて新規作成。
- issue #LOCAL-016: 実装当初は「未分類」を撮影時刻どおりの位置（セッションの間や前）に表示していたが、自動撮影中に未分類の画像が一覧の上部に出てきて、確認したいセッションの画像が埋もれるという指摘を受けた。「未分類」は撮影時刻に関わらず常に一覧の末尾にまとめて表示する方式に変更し、実現内容・受入基準を修正した。
- issue #LOCAL-034: 撮影結果を操作フローごとに整えて共有したいという要望を受け、セッション名の変更・セッション単位のダウンロード・セッション内の並べ替えを追加した。当初は範囲外としていたセッション単位のダウンロードを対象に含めた。連番は、画像ファイルの名前を変えず、ダウンロードした ZIP の中のファイル名にだけ付ける。名前と並べ替えた順序は、ウィンドウ終了時に保存データを残さない方針に合わせて永続化しない。
- issue #LOCAL-035: 撮り直しや不要な操作フローの整理を素早く行いたいという要望を受け、セッション単位の全選択（選択の切り替え）と削除を追加した。従来は範囲外としていた。誤って消す被害を減らすため、削除は確認メッセージで枚数を示し、端末フィルタで隠れている画像は対象に含めないことにした。
