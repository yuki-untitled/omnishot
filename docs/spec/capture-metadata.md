# 撮影情報（メタデータ） — 画像ごとに撮影日時・端末・OS・解像度を記録して表示する

## Issue
#LOCAL-044

## 目的（Why）
OmniShot はアプリのエビデンス採取にも使われる。エビデンスでは、画像そのものに加えて「いつ・どの端末で・どの OS の版で撮ったか」が必要になる。現状は、画像のファイル名とファイルの更新時刻しか残らず、端末や OS の版は後から分からない。撮影のたびにこれらを記録し、ギャラリーで確認できるようにして、画像を資料として扱いやすくする。

## 実現内容（What）
- 画像を1枚保存するたびに、次の5項目を、その画像の撮影情報として記録する。自動撮影・手動撮影のどちらで保存した画像も対象とする。
  - 撮影日時: 撮影した時刻。この PC のローカル時刻で、秒まで（例: `2026-10-01 12:34:56`）。
  - 端末名: 撮影した端末の名前（例: `Eidome's iPhone`）。
  - OS: OS の種類と版（例: `iOS 17.5.1`、`Android 14`）。
  - 解像度: 保存した画像の幅×高さ（ピクセル、例: `1170×2532`）。
  - 撮影の種類: 自動撮影か手動撮影か。
- 端末名または OS の版が取得できなかった項目は、「不明」と表示する。取得できなかったことで、撮影は失敗にしない。
- プレビュー（画像を開いて拡大して見る画面）に、5項目すべてを表示する。
- ギャラリーの各画像には、撮影情報を表示しない（表示名またはファイル名だけを表示する。[gallery.md](gallery.md)）。
- 撮影情報は、画像のファイルの中身（画像データ）には書き込まない。画像は従来どおりの内容で保存する。
- 撮影情報は、画像と同じ保存先（captures フォルダ）に保存する。画像を削除したときや、全消去・アプリ終了時に captures フォルダを削除したときは、その画像の撮影情報も一緒になくなる。アプリを再起動しても、画像が残っている間は撮影情報も表示される。
- 撮影情報の無い画像（この機能の追加前に保存された画像など）には、撮影情報の表示を出さない。
- 表示名の変更・並べ替え・セッション（[session-grouping.md](session-grouping.md)）への所属・ZIP ダウンロードの内容と、ZIP の中のファイル名は、従来どおり。ZIP には撮影情報の一覧を入れない。

## 受入基準
1. **自動撮影の記録**: iPhone と Android のそれぞれで自動撮影すると、保存された画像すべてに、撮影日時（秒まで）・端末名・OS の種類と版・解像度・撮影の種類「自動」が記録されること。
2. **手動撮影の記録**: 手動撮影した画像の撮影の種類が「手動」と記録されること。
3. **解像度の一致**: 記録された解像度が、保存された画像ファイルの実際の幅×高さと一致すること。
4. **ギャラリーに出さない**: ギャラリーの各画像には、撮影日時・端末名などの撮影情報が表示されず、従来どおり表示名（未設定ならファイル名）だけが表示されること。
5. **プレビューの表示**: プレビューに、撮影日時・端末名・OS・解像度・撮影の種類が表示されること。プレビューで前後の画像へ移動すると、表示が移動先の画像の撮影情報に変わること。
6. **取得できない項目**: 端末名または OS の版を取得できなかった場合も画像が保存され、取得できなかった項目が「不明」と表示されること。
7. **再起動後も残る**: 撮影情報を記録した後、画像を残したままアプリを再起動する、またはギャラリーを再読み込みしても、撮影情報が表示されること。
8. **削除と一緒になくなる**: 画像を削除すると、その画像の撮影情報も保存先から無くなること。アプリ終了時に captures フォルダが削除された後、次の起動で、以前の画像の撮影情報が残らないこと。
9. **情報の無い画像**: 撮影情報の無い画像（撮影情報のファイルを削除して再読み込みした状態）が、撮影情報の表示を出さずに従来どおり表示され、ダウンロード・削除ができること。
10. **画像と ZIP が変わらない**: 保存された画像ファイルに、撮影情報が書き込まれていないこと。ZIP のダウンロードで、ZIP の中に撮影情報の一覧が入らず、ファイル名が従来どおりであること。
11. **回帰**: 自動撮影・手動撮影のタイミング、保存されるファイル名の形式、表示名の変更、セッションの見出し・並べ替え、プレビューでの削除が従来どおり動作すること。

## 制約・関連機能
- 自動撮影の仕様は [screenshot-capture.md](screenshot-capture.md)、手動撮影は [manual-capture.md](manual-capture.md)、ギャラリーと表示名は [gallery.md](gallery.md)、セッションは [session-grouping.md](session-grouping.md) を参照。
- 撮影情報の保存先は、表示名（[gallery.md](gallery.md)）と同じく captures フォルダとする。
- 撮影情報の一覧を ZIP や PDF・Excel で書き出す機能は、この仕様の対象外とする。

## 変更理由
- issue #LOCAL-044: 「今後追加した方がいい機能」の検討で、マニュアル作成とエビデンス採取の用途では「いつ・どの端末で」の記録が必要という提案があり、メタデータの記録と表示を追加することにした。記録する項目は、ユーザーが「日時・端末名・OS・解像度」を選び、撮影の種類（自動・手動）を加えた。表示は、ギャラリーでは日時と端末名のみ、プレビューで全項目とした。ZIP への一覧の同梱は、ユーザーの選択により今回は対象外とした。
- issue #LOCAL-044: 当初はギャラリーの各画像に日時と端末名を表示する仕様にしたが、実装して確認した際に、ギャラリーにはファイル名だけでよく、撮影情報は画像を開いたとき（プレビュー）に見られれば足りるという指示を受け、ギャラリーの表示をやめてプレビューだけに表示する形に改めた。
