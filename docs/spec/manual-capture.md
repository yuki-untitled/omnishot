# 手動撮影 — 自動検知に加えて任意のタイミングでシャッターを切れるようにする

## Issue
#LOCAL-015

## 目的（Why）
自動撮影（静的モード・動的モード）は画面の変化や静止を検知して撮影するため、検知条件に合わない一瞬（アニメーション中に狙いたい瞬間、変化量が検知の閾値に満たない微細な違いなど）を撮り漏らすことがある。また、ユーザーが「今の画面を確実に残したい」と判断した瞬間に、自動検知を待たずに撮影したい場面もある。任意のタイミングでシャッターを切れる手動撮影を用意することで、自動検知の撮り漏らしを補い、狙った瞬間を確実に記録できるようにする。

## 実現内容（What）
- 撮影の設定欄2行目に、「手動撮影」ボタンを追加する。表示順は「端末」「更新」「手動撮影」「自動撮影」「停止」「ステータス」とする。
- 手動撮影ボタンは、自動撮影が「停止中」「撮影中」のどちらの状態でも押せる。
- 手動撮影ボタンを押すと、その時点でプルダウンに選択されている端末の画面を1枚だけ撮影し、キャプチャ保存先に保存する。撮影対象の端末は、[device-selection.md](device-selection.md)で選択されている端末を、自動撮影と共有して用いる。
- 自動撮影が「停止中」に手動撮影を行う場合、[screenshot-capture.md](screenshot-capture.md)の常時接続（iOSのストリーミング等）を新たに起動せず、1回分の取得だけで完結させる。常時接続の起動・待機を挟まないぶん、接続状況によっては常時接続より短時間で完了する。
- 端末が選択されていない場合（0台、または2台以上で未選択）に手動撮影ボタンを押すと、「撮影する端末を選択してください」と表示し、撮影しない。
- 選択した端末が接続されていない場合に手動撮影ボタンを押すと、「選択した端末が接続されていません」と表示し、撮影しない。
- 自動撮影が「撮影中」の状態で手動撮影ボタンを押しても、自動撮影の検知・待機タイミング（静的モードの静止待ち時間、動的モードの判定回数のカウント）には影響を与えない。手動撮影は自動撮影の検知ロジックとは独立した1回撮影として動作する。
- 手動撮影の処理中（撮影〜保存が完了するまで）は、手動撮影ボタンを再度押せない。処理が完了すると再び押せるようになる。
- 手動撮影で保存された画像は、自動撮影で保存された画像と区別できるようにする。
  - ファイル名に、自動撮影の画像とは異なる印を含める（例: 自動撮影が `iOS_20260922_101010.png` の形式のとき、手動撮影は `Manual_iOS_20260922_101010.png` のように、見分けがつく形にする）。
  - ギャラリー上でも、手動撮影された画像であることが分かる表示（バッジなど）を付ける。
- 手動撮影で保存された画像は、[gallery.md](gallery.md)の一覧表示・全選択/個別選択・一括ダウンロード・一括削除・表示名編集の対象に、自動撮影の画像と同様に含まれる。

## 受入基準
1. **表示順**: 設定欄2行目に「端末」「更新」「手動撮影」「自動撮影」「停止」「ステータス」が、この順で表示されること。
2. **停止中でも撮影できる**: 自動撮影を開始していない状態で「手動撮影」を押すと、選択中の端末の画面が1枚保存され、ギャラリーに反映されること。
3. **撮影中でも撮影できる**: 自動撮影が動作中（静的/動的いずれのモードでも）に「手動撮影」を押すと、自動撮影の待機・判定タイミングに影響を与えずに1枚追加で保存されること。
4. **端末未選択時の拒否**: 端末が2台以上接続され未選択の状態で「手動撮影」を押すと、「撮影する端末を選択してください」と表示され、撮影されないこと。
5. **端末未接続時の拒否**: 選択した端末が接続されていない状態で「手動撮影」を押すと、「選択した端末が接続されていません」と表示され、撮影されないこと。
6. **連打時の多重保存防止**: 「手動撮影」を押した直後、保存が完了するまでの間は再度押しても撮影が実行されず、完了後は再び押せること。
7. **自動/手動の区別**: 手動撮影で保存された画像は、ファイル名とギャラリー表示の両方で、自動撮影の画像と区別できること。
8. **ギャラリーでの取り扱い**: 手動撮影で保存された画像が、全選択・個別選択・一括ダウンロード・一括削除・表示名編集のいずれの操作でも、自動撮影の画像と同様に扱えること。

## 制約・関連機能
- 撮影の基本仕様・既知の制限事項は [screenshot-capture.md](screenshot-capture.md) を参照。
- 撮影対象の端末選択は [device-selection.md](device-selection.md) を参照。手動撮影は、この選択状態をそのまま利用する。
- 撮影画像の一覧・管理は [gallery.md](gallery.md) を参照。
- 画面は [native-window.md](native-window.md) のネイティブウィンドウ内に表示される。

## 変更理由
- issue #LOCAL-015: 自動検知では撮り漏らす瞬間を補うため、任意のタイミングでシャッターを切れる手動撮影機能の要望を受けて新規作成。
- issue #LOCAL-015: ボタンの表示順を「手動撮影→自動撮影開始→停止」にしたいという指定を受け、実現内容・受入基準に表示順を明記し、実装（ボタンの配置順）を修正。
- issue #LOCAL-015: 「自動撮影開始」ボタンの表記が長いという指摘を受け、ボタン名を「自動撮影」に短縮したことに合わせ、表示順の記述を修正。
- issue #LOCAL-015: 実機で、自動撮影が停止中の手動撮影（iOS）が「Remote end closed connection without response」で失敗する不具合を確認した。原因は、1回の撮影のためだけにiOSの常時ストリーミング接続を新規起動しており、その起動・接続が不安定だったこと。常時接続を起動せず、1回分の取得だけで完結させる方式に修正し、実現内容に明記した。
