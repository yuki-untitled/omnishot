# 接続確認と準備の手順 — 端末の準備ができているかを自動で判定し、手順は使い方ページで案内する

## Issue
#LOCAL-038、#LOCAL-039

## 目的（Why）
初めて使う人が、iPhone・Android で撮影を始められず、そこで止まってしまう。原因は次のとおり。

- iPhone は、設定の「デベロッパモード」の項目が、Xcode などの開発ツールを使うまで表示されない。項目が見つからず、iPhone に不慣れな人は先へ進めない。Windows には Xcode がなく、項目を表示する手段がない。
- Android は、USB デバッグの許可ダイアログが出ないままだと、撮影できない。出ない理由も、画面からは分からない。
- どちらも、いま何が足りないのかが画面に出ないため、手順書を最初から順に確かめるしかない。

そこで、接続した端末の状態を自動で判定して足りない項目を示し、実行できる操作はボタンで進められる「接続確認」を設ける。

また、準備の手順の文章（設定ガイド）と、アプリの使い方（使い方ページ）が別々の場所にあり、どこを見ればよいかが分かりにくい。端末の選択と同じ場所に接続確認を置き、手順の文章は使い方ページのタブにまとめることで、「端末をつなぐ → 状態を確認する → 足りなければ手順を見る」を、迷わずたどれるようにする（#LOCAL-039）。

## 実現内容（What）
### 接続確認の開き方
- 画面上部の右側で、「使い方」ボタンの左に「接続確認」ボタンを置く（右から、アプリ終了・使い方・接続確認の順）。撮影の設定欄（[device-selection.md](device-selection.md)）ではなく、画面上部に置く。
- 「接続確認」ボタンを押すと、接続確認の画面（ウィンドウの中央に重ねて表示する画面）が開く。閉じるボタンで閉じる。
- 端末の「更新」ボタンと違い、自動撮影が「撮影中」の間も「接続確認」ボタンを押せる。
- 画面上部の「設定ガイド」ボタンは廃止する。

### 状態の確認
- 接続確認の画面には、「iPhone」と「Android」の2つの区画を横に並べて表示する（画面の幅が狭いときは縦に並べる）。左が iPhone、右が Android。それぞれの区画に、接続している端末の状態を出す。
- 画面を開いている間、2秒ごとに状態を確認し直して表示を更新する。閉じると確認をやめる。撮影中も更新する。
- 各項目は、達成済み（✅）・未達成（⚠️）・確認できない（❔）のいずれかで表示し、未達成の項目には、すぐ行う対処を1行で示す。
- USB で接続された端末が1台もないときは、その区画に「端末が接続されていません」と表示し、その下に対処（iPhone は「USB で iPhone を接続してください。」、Android は「USB で Android 端末を接続してください。」と、接続しても表示されないときに「USBデバッグ」がオンか確認する旨）を表示する。iPhone と Android のそれぞれの区画で、独立して表示する。複数台あるときは、端末ごとに項目を表示する（端末名と、端末の識別子の末尾6文字で区別する。表示は [device-selection.md](device-selection.md) の端末名と同じ）。
- 確認する項目がすべて達成済みの端末には、「撮影の準備ができています」と表示する。
- 各区画に、「手順を見る」リンクを置く。押すと、使い方ページの該当のタブ（「iPhone の準備」または「Android の準備」）が開く。
- 「閉じる」ボタンは、接続確認の画面の下端に置き、内容をスクロールしても、常に見える位置に固定する。
- 接続確認の画面の大きさは固定する。端末が接続されていないときも、1台以上接続されているときも、幅（最大 720px。ウィンドウが狭いときはウィンドウの幅の 90%）と高さ（最大 460px。ウィンドウが低いときはウィンドウの高さの 90%）が変わらない。内容が収まらないときは、状態を表示する部分の中だけをスクロールする。
- 接続確認は、撮影できるかどうかの判定や、端末の選択には影響しない。端末の一覧は、従来どおり「更新」ボタンで検出する。

### iPhone の項目
1. **接続**: USB で接続された iPhone を検出できること。検出できないときは、USB で接続する旨を表示する。Windows で iTunes が入っていないことが原因で検出できない場合は、iTunes をインストールする旨を表示する。
2. **信頼**: iPhone がこのコンピュータを信頼していること。信頼していないときは、iPhone に表示される「このコンピュータを信頼しますか？」で「信頼」を押す旨を表示する。
3. **デベロッパモード**: iPhone のデベロッパモードがオンであること。
   - オフのときは、「デベロッパモードの項目を表示する」ボタンを出す。
   - オンかオフかを確認できないとき（信頼していない端末など）は、❔ で表示し、ボタンは出さない。
- 「デベロッパモードの項目を表示する」ボタンを押すと、実行の前に、次の内容の確認メッセージを表示する。
  - iPhone の設定に「デベロッパモード」の項目を表示すること。
  - パスコードを設定していない iPhone は、デベロッパモードがオンになり、iPhone が自動で再起動すること。
  - キャンセルすると何も行わない。
- 実行した結果は、その端末の下に表示する。その端末が撮影できる状態になった（「撮影の準備ができています」の表示になった）ときは、結果のメッセージを消す。オンにした後まで、「オンにしてください」などの案内が残らないようにするため。
  - 項目を表示できたとき: 「iPhone の『設定』＞『プライバシーとセキュリティ』の一番下の『デベロッパモード』をオンにして、再起動してください」と表示する。パスコードを設定している iPhone は、項目の表示までを行い、オンにする操作と再起動は iPhone の画面で行う。
  - パスコードを設定していない iPhone で、そのままオンになったとき: 「iPhone が再起動します。再起動後、表示される『オンにする』を押してください」と表示する。
  - 失敗したとき: 失敗した理由と、対処を表示する。
- iPhone がデベロッパモードをオンにできる OS のバージョンではないなど、項目を表示できない場合は、その理由を表示する。

### Android の項目
1. **接続と USB デバッグ**: USB で接続された Android 端末を検出できること。検出できないときは、USB で接続する旨と、「開発者オプション」で「USB デバッグ」をオンにする旨を表示する（USB デバッグをオンにする操作は、端末の画面でしか行えないため、ボタンは出さない）。
2. **許可**: 端末が、このコンピュータからの USB デバッグを許可していること。
   - 許可していない（許可待ちの）ときは、「許可を要求する」ボタンを出す。
   - 端末が「オフライン」など、ほかの状態のときは、その状態と対処を表示する（内容は [device-selection.md](device-selection.md) で、撮影できない端末の理由と対処としてログに出すものと同じ）。
- 「許可を要求する」ボタンを押すと、実行の前に、次の内容の確認メッセージを表示する。
  - 端末に「USB デバッグを許可しますか？」を表示し直すために、adb サーバーを起動し直すこと。
  - Android Studio など、ほかのツールが adb サーバーを使っている場合、そのツールと端末の接続が一時的に切れること（[native-window.md](native-window.md) の終了時の adb サーバーの停止と同じ）。
  - キャンセルすると何も行わない。
- 実行した後、端末に許可のダイアログが表示される。端末で「許可」を押すと、次の確認で ✅ に変わる。「常に許可する」にチェックを入れると、次回から表示されなくなる旨も表示する。

### 自動撮影中の操作
- 自動撮影が「撮影中」の間は、「デベロッパモードの項目を表示する」「許可を要求する」のどちらも実行できない。押すと、「自動撮影中は実行できません。停止してからもう一度押してください。」と表示し、端末・adb サーバーには何も行わない。撮影中の端末の撮影を止めないため。

### 使い方ページのタブ
- 使い方ページ（画面上部の「使い方」ボタンで開く）を、次の4つのタブで切り替えられるようにする。最初に開いたときは、「使い方」のタブを表示する。
  1. **使い方**: 基本操作・モードの違い・撮影の流れ・ギャラリーの使い方（保存名を含む）・セッション（名前の変更、セッション単位のダウンロード・全選択・削除、並べ替え。詳細は [session-grouping.md](session-grouping.md)）。
  2. **iPhone の準備**: iPhone の準備の手順。従来の設定ガイドの手順の文章（Windows の iTunes、デベロッパモードのオン、再起動、「信頼」）を、内容を変えずに載せる。加えて、「設定に『デベロッパモード』の項目が見つからないときは、接続確認の『デベロッパモードの項目を表示する』ボタンを押してください」と案内する。
  3. **Android の準備**: Android の準備の手順。従来の設定ガイドの手順の文章（ビルド番号、開発者オプション、USB デバッグ、許可）を、内容を変えずに載せる。加えて、「許可のダイアログが表示されないときは、接続確認の『許可を要求する』ボタンを押してください」と案内する。
  4. **困ったとき**: 端末が見つからない・撮影を始められないときは、接続確認を開いて足りない項目を確認する旨、画面の表示が崩れたときやログの表示が遅いときは、アプリを終了して起動し直す旨、USB 接続に問題があるときはケーブルを挿し直す旨。
- URL に、開くタブを指定できる（使い方ページの「iPhone の準備」「Android の準備」を直接開ける）。接続確認の「手順を見る」リンクは、これを使う。
- 使い方ページの見た目（配色・ボタン・タブ）は、アプリ本体と同じ部品を使い、そろえる。
- 使い方ページの左上の「← 戻る」で、メイン画面に戻れる。

### 変更しないもの
- 手順の文章の内容は、従来から変えない（置き場所を、設定ガイドから使い方ページのタブに移す）。
- 撮影の開始・端末の選択の動作は変えない。

## 受入基準
1. **接続確認を開く**: 画面上部の「使い方」ボタンの左に「接続確認」ボタンがあり、押すと接続確認の画面が開くこと。画面上部に「設定ガイド」ボタンがないこと。自動撮影中も、「接続確認」ボタンを押せること。
2. **状態の表示**: iPhone を USB で接続し、デベロッパモードがオフの状態で接続確認を開くと、iPhone の区画に「接続」「信頼」が ✅、「デベロッパモード」が ⚠️ で表示され、「デベロッパモードの項目を表示する」ボタンが出ること。
3. **未接続**: 端末を1台も接続せずに接続確認を開くと、「iPhone」「Android」の両方の区画に、それぞれ「端末が接続されていません」と表示され、その下に接続する旨の案内が表示されること。この状態と、端末を接続した状態とで、接続確認の画面の大きさ（幅・高さ）が変わらないこと。「閉じる」ボタンが、どちらの状態でも画面の下端に表示され、状態の表示がスクロールするときも動かないこと。2つの区画が、幅の広いウィンドウでは左右に並び、狭い幅（640px 以下）では上下に並ぶこと。接続確認の画面が、ウィンドウの大部分を覆わない大きさ（幅は最大 720px）であること。
4. **自動更新**: 接続確認を開いたまま iPhone を接続する、または端末で「信頼」・「許可」を押すと、操作しなくても、数秒のうちに項目が ✅ に変わること。閉じると、状態の確認が行われなくなること。
5. **確認メッセージ**: 「デベロッパモードの項目を表示する」「許可を要求する」を押すと、実行の前に、上記の内容の確認メッセージが表示されること。キャンセルすると、iPhone・Android 端末・adb サーバーに何も行われないこと。
6. **iPhone の項目の表示**: パスコードを設定している iPhone で、確認メッセージを確定すると、iPhone の「設定」＞「プライバシーとセキュリティ」に「デベロッパモード」の項目が表示され、「デベロッパモードをオンにして、再起動してください」と表示されること（項目の表示に成功しているにもかかわらず、失敗と表示されないこと）。
7. **デベロッパモードがオンの確認**: iPhone でデベロッパモードをオンにして再起動した後、「デベロッパモード」が ✅ になり、「撮影の準備ができています」と表示されること。このとき、「デベロッパモードをオンにして、再起動してください」などの結果のメッセージが表示されていないこと。その iPhone で撮影を開始できること。
8. **Android の許可**: 許可待ちの Android 端末で、「許可を要求する」を確定すると、端末に「USB デバッグを許可しますか？」が表示されること。「許可」を押すと、「許可」が ✅ になり、「撮影の準備ができています」と表示され、「端末の画面で『許可』を押してください」などの結果のメッセージが消えること。
9. **USB デバッグがオフの端末**: USB デバッグがオフの Android 端末を接続した場合、「USB デバッグをオンにしてください」と手順を示し、ボタンは出ないこと。
10. **複数台**: iPhone と Android 端末をそれぞれ接続した場合、それぞれの区画に、その OS の端末だけが表示されること。同じ OS の端末が複数台ある場合は、端末ごとに表示されること。
11. **撮影中の操作**: 自動撮影中に「デベロッパモードの項目を表示する」「許可を要求する」を押すと、「自動撮影中は実行できません。」と表示されるだけで、撮影中の自動撮影が止まらないこと。接続確認を開いていない間は、状態の確認が行われないこと。
12. **手順を見る**: 各区画の「手順を見る」を押すと、使い方ページの「iPhone の準備」「Android の準備」のタブが、それぞれ開いた状態で表示されること。
13. **使い方ページのタブ**: 使い方ページを開くと、最初に「使い方」のタブが表示され、「iPhone の準備」「Android の準備」「困ったとき」を切り替えられること。「iPhone の準備」「Android の準備」に、従来の設定ガイドの手順の文章が、内容を変えずに載っていること。それぞれに、接続確認のボタンの案内が載っていること。
14. **使い方のタブの内容**: 「使い方」のタブに、セッションの説明（名前の変更・セッション単位のダウンロード・全選択・削除・並べ替え）が載っていること。
15. **回帰**: 端末の更新・選択・撮影の開始、ギャラリーの操作が、従来どおり動作すること。使い方ページの「← 戻る」でメイン画面に戻れること。

## 制約・関連機能
- 端末の検出・選択・撮影できない端末の理由と対処、設定欄の配置は [device-selection.md](device-selection.md) を参照。
- ウィンドウ終了時の adb サーバー・iOS のトンネルの後始末は [native-window.md](native-window.md) を参照。
- 設定ガイドを起動時に自動表示しないことは [bugs/LOCAL-013_設定ガイドの次回から表示しないを廃止し起動時の自動表示をやめる.md](bugs/LOCAL-013_設定ガイドの次回から表示しないを廃止し起動時の自動表示をやめる.md) を参照。「設定ガイド」ボタンは、本仕様（#LOCAL-039）で廃止した。
- デベロッパモードの項目の表示は、iPhone の OS が用意している機能を使う。パスコードを設定している iPhone では、スイッチのオンと再起動を、アプリから行うことはできない。
- USB デバッグのオンは、Android 端末の画面でしか行えない。アプリから行うことはできない。
- 「許可を要求する」は、adb サーバーを起動し直す。ほかのツールとの共有についての注意は上記のとおり。
- Windows での動作（iTunes が入っていない場合の判定、デベロッパモードの項目の表示）は、実機で未確認。Mac の実機で確認したうえで、Windows は未確認として配布する。

## 変更理由
- issue #LOCAL-038: iPhone の設定に「デベロッパモード」の項目が表示されず、初めて使う人が iOS で撮影できずに止まるという課題を受けて新規作成。Windows には Xcode がなく、項目を表示する手段がないことも背景にある。Mac の実機（iPhone・iOS 27.0）で、go-ios の `devmode enable` が、パスコードを設定した iPhone で設定に項目を表示すること（コマンドはエラーで終了するが、メッセージは「項目を表示した」ことを示す）を確認済み。Android については、USB デバッグをアプリからオンにできないため、許可のダイアログの再表示と、状態の表示に範囲を絞った。
- issue #LOCAL-039: 「閉じる」ボタンを、画面の末尾（下端）に固定して置くことにした。内容が長くなっても、ボタンがスクロールの先に隠れないようにするため。
- issue #LOCAL-039: 端末が接続されていない状態で、何が起きているかが分かりにくく、また端末の接続に合わせて画面の大きさが変わって見づらいという指摘を受け、「端末が接続されていません」の表示を iPhone・Android それぞれに出すこと、画面の大きさを固定することを追記した。
- issue #LOCAL-039: 接続確認の画面は、iPhone と Android を横に並べて、両方の状態を一目で見られるようにした。また、デベロッパモードをオンにした後も、「オンにしてください」の案内が残る不具合があったため、準備ができた端末の結果のメッセージは消すことにした。
- issue #LOCAL-039: 状態の確認が設定ガイドの中にあり、端末の選択（更新ボタン）と離れていたため、更新ボタンの隣の「接続確認」ボタンに独立させた。あわせて、設定ガイドの手順の文章を使い方ページのタブに統合し、画面上部の「設定ガイド」ボタンを廃止した。状態の確認は、端末を確かめながら操作する場面が多いため、撮影中も開けるようにした。
- issue #LOCAL-041: ウィンドウの最小の幅を詰めるため、「接続確認」ボタンを、端末の「更新」ボタンの隣から、画面上部の「使い方」ボタンの左へ移した。
