# バグ修正: 起動時と終了時の後始末が、アプリが作っていないファイルやプロセスに影響する

## Issue
#LOCAL-042

## 不具合現象と再現手順（Why）
### 発生している現象
アプリの起動時・終了時の後始末が、アプリ自身が作っていないファイルやプロセスまで対象にしており、ユーザーの別のアプリや、OS のファイルに影響する。

1. **Windows: 終了時に、無関係のフォルダを消す。** 一時フォルダにある、名前に「ios」または「adb」を含むフォルダを、すべて削除する。他のアプリが作ったフォルダも消える。アプリ自身が一時フォルダに作るのは、iOS の画面取得に使う一時ファイル1つだけで、これは使い終わったときにその場で削除している。
2. **Mac: 終了時に、OS の設定ファイルを消す。** `~/Library/Preferences/com.apple.selfidentity.plist` を削除する。これは macOS の設定ファイルで、アプリが作ったものではない。go-ios が作る識別情報（selfIdentity.plist）は、これとは別のファイルで、保存先も別（[LOCAL-032](LOCAL-032_アプリ化するとiOSのトンネルが起動できずトンネルの起動が連鎖し続ける.md)）。
3. **起動時に、ポート 5001 に関係するプロセスを、何であっても強制終了する。**
   - Windows: 「5001」を含む行に一致するプロセスを終了する。ポート番号ではなく、プロセス番号などに「5001」を含む、無関係のプロセスも対象になる。
   - Mac: ポート 5001 へ接続している側のプロセス（例: ブラウザ）も終了する。
   - どちらも、別のアプリがポート 5001 で待ち受けていた場合、そのアプリも終了する。

### 再現手順
1. （Windows）一時フォルダに、名前に「ios」を含むフォルダ（例: `my-ios-notes`）を作り、アプリを起動して終了する。フォルダが消える。
2. （Mac）`~/Library/Preferences/com.apple.selfidentity.plist` がある状態で、アプリを起動して終了する。ファイルが消える。
3. ポート 5001 で待ち受ける別のプログラム（例: `python3 -m http.server 5001`）を起動した状態で、アプリを起動する。そのプログラムが強制終了される。
4. 期待値: 1・2 のファイルは残り、3 の別のプログラムは終了されない。実際: いずれも、消える・終了される。

## 修正内容（What）
### 根本原因
- 1・2: 終了時の後始末の対象を、名前や場所の一致だけで決めていて、アプリ自身が作ったものかを確かめていない。アプリが作らないファイルまで消している。
- 3: 起動時の「前回のプロセスの整理」が、そのプロセスが OmniShot かを確かめず、ポート番号の単純な文字列の一致だけで、関係するすべてのプロセスを対象にしている。

### 修正方針
- **終了時に消すのは、アプリ自身が作ったものだけにする。**
  - 撮影データの保存フォルダ（captures）は、従来どおり削除する。
  - Windows の一時フォルダの、名前に「ios」「adb」を含むフォルダの削除はやめる。
  - Mac の `com.apple.selfidentity.plist` の削除はやめる。
  - go-ios の識別情報（[LOCAL-032](LOCAL-032_アプリ化するとiOSのトンネルが起動できずトンネルの起動が連鎖し続ける.md) のアプリ用フォルダ）は、従来どおり消さない。
- **起動時にポート 5001 の使用者を整理するときは、待ち受けているプロセスだけを対象にし、そのプロセスが OmniShot のときだけ終了する。**
  - 「待ち受けているプロセス」とは、ポート 5001 で接続を待ち受けている（LISTEN している）プロセス。そのポートへ接続しているだけの側（ブラウザなど）は、対象にしない。
  - 「OmniShot のプロセス」とは、配布版は実行ファイル名が `OmniShot` で始まるもの（Windows の配布ファイル `OmniShot-v1.3.0-windows-x64.exe` のように、名前にバージョンなどが付いたものを含む。大文字と小文字は区別しない）、開発時は `run.py` を実行している Python のプロセス。
  - 待ち受けているプロセスが OmniShot 以外だった場合は、終了せず、「ポート 5001 を他のアプリが使っているため、起動できません。そのアプリを終了してから、もう一度起動してください。」というメッセージをダイアログで表示し、アプリを起動せずに終了する。

## 受入基準（再発防止・回帰テスト）
1. **Windows の一時フォルダ**: 一時フォルダに、名前に「ios」「adb」を含むフォルダ（例: `my-ios-notes`）を作ってアプリを起動・終了しても、そのフォルダが残ること。
2. **Mac の設定ファイル**: `~/Library/Preferences/com.apple.selfidentity.plist` がある状態で、アプリを起動・終了しても、そのファイルが残ること。
3. **撮影データの後始末**: アプリを終了すると、撮影データの保存フォルダ（captures）が削除されること。go-ios の識別情報は、消えずに残ること（従来どおり）。
4. **接続しているだけの側**: ポート 5001 へ接続しているだけのプロセス（例: ブラウザのタブ）がある状態でアプリを起動しても、そのプロセスが終了されないこと。
5. **前回の OmniShot**: OmniShot が待ち受けたまま残っている状態で、もう一度アプリを起動すると、前の OmniShot が終了して、新しく起動できること。
6. **他のアプリ**: ポート 5001 で、OmniShot 以外のプログラム（例: `python3 -m http.server 5001`）が待ち受けている状態でアプリを起動すると、そのプログラムは終了されないこと。「ポート 5001 を他のアプリが使っているため、起動できません。…」のメッセージがダイアログで表示され、アプリが起動せずに終了すること。
7. **Windows の誤爆**: Windows で、プロセス番号などに「5001」を含む別のプロセスがあっても、それが終了されないこと。
8. **回帰**: アプリの通常の起動・終了、撮影、iOS のトンネルと adb サーバーの終了時の停止（[native-window.md](../native-window.md)）が従来どおり動作すること。
