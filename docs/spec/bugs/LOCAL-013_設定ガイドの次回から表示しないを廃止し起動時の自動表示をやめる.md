# バグ修正: 設定ガイドの「次回から表示しない」が機能しない（外せない・再起動で保持されない）ため、廃止して起動時の自動表示もやめる

## Issue
#LOCAL-013

## 不具合現象と再現手順（Why）
### 発生している現象
設定ガイドの「次回から表示しない」に次の不具合がある。

- 起動直後の最初の操作で、チェックを外せない（ユーザー報告）。
- チェックを外してガイドを閉じても、保存されている「表示しない」の設定が解除されない。
- ガイドを開いたときの「次回から表示しない」の表示が、保存されている設定を反映しない。
- アプリを再起動すると、「表示しない」の設定が保持されない。本アプリはネイティブウィンドウ（[native-window.md](../native-window.md)）で、ブラウザの保存領域（`localStorage`）を終了のたびに消去して動作する。そのため、この設定は再起動をまたいで残らず、起動のたびに設定ガイドが自動表示される。

本アプリはスタンドアローンで動作し、端末に不要なデータを残さない方針である。設定ガイドの表示可否のためだけに、再起動後も残る保存データを追加することはしない。

### 再現手順
1. Mac で `python3 run.py` によりアプリを起動する（設定ガイドが自動表示される）
2. 「次回から表示しない」にチェックを入れて「閉じる」を押す
3. アプリを終了して再度起動する
4. 期待値・実際の差異
   - 期待値: 「表示しない」を選んだので、ガイドが自動表示されない
   - 実際: ガイドが再び自動表示される（設定が保持されていない）

## 修正内容（What）
### 根本原因
- 「表示しない」の設定を、再起動のたびに消去されるブラウザの保存領域に保存しており、再起動をまたいで保持できない。
- 保存する処理のみで、設定を解除する処理と、保存状態をチェックに反映する処理がない。

### 修正方針
- 設定ガイドの「次回から表示しない」のチェックボックスを廃止する。
- 起動時に設定ガイドを自動表示しない。ガイドは、ヘッダーの「設定ガイド」ボタンを押したときだけ表示する。
- ガイドは「閉じる」ボタンで閉じられる。閉じたことによる保存データは残さない。
- ガイドの見出しから「初回」の語を除く（起動時に自動表示されなくなるため）。
- ガイドの手順の内容・タブの構成は変えない。

## 受入基準（再発防止・回帰テスト）
1. **自動表示の廃止**: アプリを起動しても、設定ガイドが自動表示されないこと。
2. **ボタンでの表示**: 「設定ガイド」ボタンを押すと、設定ガイドが表示されること。何度でも開閉できること。
3. **チェックボックスの廃止**: 設定ガイドに「次回から表示しない」が表示されないこと。
4. **保存データを残さない**: ガイドの表示・非表示に関する保存データが、ブラウザの保存領域にもファイルにも作られないこと。
5. **回帰（タブ切り替え）**: ガイド内の iOS / Android のタブが、従来どおり切り替わること（起動直後の最初のクリックについては [LOCAL-012](LOCAL-012_起動直後の最初のクリックが設定ガイドのタブに効かない.md) を参照）。
6. **回帰（ガイド以外の操作）**: 撮影・ギャラリーなど、ガイド以外の機能が従来どおり動作すること。
