# バグ修正: 「端末が見つかりません」と表示されている間に、撮影できてしまう

## Issue
#LOCAL-023

## 不具合現象と再現手順（Why）
### 発生している現象
端末のプルダウンに「端末が見つかりません」と表示されている状態で、「手動撮影」または「自動撮影」を押すと、撮影できてしまうことがある。画面では端末が無いことになっているのに、ユーザーが一覧で確認していない端末が撮影される。

これは次の2つの場面で起きる。
- アプリの起動時の検出に端末が間に合わず「端末が見つかりません」と表示されたが、実際には端末が接続されている場合
- 「端末が見つかりません」と表示された後に端末を接続し、「更新」を押さずに撮影のボタンを押した場合

### 再現手順
1. 端末を接続せずにアプリを起動する（プルダウンに「端末が見つかりません」と表示される）
2. 端末を1台接続する（「更新」は押さない）
3. 「自動撮影」または「手動撮影」を押す
   - 期待値: 撮影のボタンは押せず、撮影されない。端末を一覧に出すには「更新」を押す必要がある
   - 実際: 接続した端末で撮影が始まる（自動撮影）、または1枚保存される（手動撮影）。プルダウンは「端末が見つかりません」のまま

## 修正内容（What）
### 根本原因
- プルダウンで端末が選ばれていないとき、撮影の依頼は「端末の指定なし」でサーバーに送られる。
- サーバーは、端末の指定が無い依頼を受けると、その場で端末を検出し直し、1台だけ見つかればその端末で撮影していた。そのため、画面の一覧に無い端末が撮影される。
- 画面側も、端末が0台のときに撮影のボタンを押せる状態のままにしていた。

### 修正方針
- プルダウンが「端末が見つかりません」または「検出中...」のとき、「手動撮影」と「自動撮影」のボタンを押せなくする。端末を一覧に出すには「更新」を押す（端末の一覧は起動時と更新ボタンでだけ検出する、という [device-selection.md](../device-selection.md) の方針どおり）。
- 端末が2台以上で未選択のときは、ボタンを押せるままにする。押した場合は、手動撮影・自動撮影のどちらも「撮影する端末を選択してください」と表示し、撮影しない。
- サーバーは、端末の指定が無い撮影の依頼を受けても、自分で端末を選ばない。「撮影する端末が選ばれていません」と表示して、撮影しない。
- 選択した端末が接続されていない場合の扱い（「選択した端末が接続されていません」と表示して撮影しない）は変えない。

## 受入基準（再発防止・回帰テスト）
1. **0台のときは押せない**: 再現手順1のとき、「手動撮影」と「自動撮影」のボタンが押せない（無効の表示になる）こと。
2. **接続しても更新前は押せない**: 再現手順2の後も、「更新」を押すまでは「手動撮影」と「自動撮影」が押せないままで、撮影されないこと。
3. **更新すると押せる**: 再現手順2の後に「更新」を押すと、端末がプルダウンに表示されて選択され、「手動撮影」と「自動撮影」が押せるようになり、その端末で撮影できること。
4. **検出中は押せない**: 「更新」を押してから一覧が表示されるまでの間（「検出中...」の表示中）は、「手動撮影」と「自動撮影」が押せないこと。
5. **2台以上で未選択**: 端末が2台以上で未選択のとき、「手動撮影」と「自動撮影」は押せ、押すとどちらも「撮影する端末を選択してください」と表示され、撮影されないこと。
6. **サーバー側の拒否**: 端末の指定が無い撮影の依頼（手動撮影・自動撮影のどちらも）をサーバーが受けたとき、接続されている端末の数に関わらず撮影せず、「撮影する端末が選ばれていません」というメッセージを返すこと。
7. **回帰**: 端末が1台のとき自動で選ばれて撮影できること、選択した端末が抜かれた状態で押すと「選択した端末が接続されていません」と表示されること、撮影中の操作の制限、切断時の再接続（[LOCAL-017](LOCAL-017_ストリーム接続の一時的な切断で自動撮影全体が停止する.md)）が従来どおりであること。
