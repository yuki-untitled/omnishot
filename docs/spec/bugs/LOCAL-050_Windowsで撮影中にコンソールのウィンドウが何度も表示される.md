# バグ修正: Windows で、Android の撮影中にコンソールのウィンドウが何度も表示される

## Issue
#LOCAL-050

## 不具合現象と再現手順（Why）
### 発生している現象
Windows 版の OmniShot で Android 端末の画面を取得している間、「プロセスはコード 0x00000000 で終了しました」と表示されるコンソールのウィンドウが、何度も開く。

### 再現手順
1. Windows で、Android 端末を USB で接続して OmniShot でプレビュー・撮影を始める
2. 画面の取得のたびに、コンソールのウィンドウが開く
3. 期待値・実際の差異
   - 期待値: コンソールのウィンドウは表示されない
   - 実際: 画面を取得するたびに表示される

## 修正内容（What）
### 根本原因
- Android の画面は、1コマごとに `adb exec-out screencap` を起動して取得する。この起動だけ、コンソールのウィンドウを出さない指定（`CREATE_NO_WINDOW`）が付いていなかった。ほかの adb・go-ios・netstat の起動には付いている
- 端末が一覧に出ない不具合（[LOCAL-049](LOCAL-049_Windowsのadbが接続方法を出さずAndroid端末が一覧に出ない.md)）で撮影まで進めなかったため、Windows 実機で初めて分かった

### 修正方針
- 画面の取得の起動にも、コンソールのウィンドウを出さない指定を付ける

## 受入基準（再発防止・回帰テスト）
1. **再現手順の検証**: Windows で Android 端末の撮影中に、コンソールのウィンドウが表示されないこと（実機で確認）。
2. **起動の指定**: 画面を取得するプロセスの起動に、コンソールのウィンドウを出さない指定が付くこと。
3. **回帰**: 画面の取得の結果・コマンドの組み立て（端末の指定・`-p`）が変わらないこと。
