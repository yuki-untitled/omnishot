# バグ修正: 新しい順でも新しいセッションが上に表示されない

## Issue
#LOCAL-037

## 不具合現象と再現手順（Why）
### 発生している現象
ギャラリーの並び順が「新しい順」でも、新しいセッション（セッション2、3…）が上に表示されず、セッション1が一番上に表示されることがある。撮影した直後の画像を確認するために、セッションが増えるほど画面を下へスクロールする必要があり、確認しづらい。

### 再現手順
1. iOS 端末を選んで自動撮影を開始し、数枚撮影して停止する（セッション1。ファイル名は `iOS_…`）。
2. Android 端末を選んで自動撮影を開始し、数枚撮影して停止する（セッション2。ファイル名は `Android_…`）。
3. ギャラリーの並び順が「新しい順」であることを確認する。
4. 期待値: セッション2が上、セッション1が下に表示される。実際: セッション1（iOS）が一番上に表示される。

同様に、プレフィックスを途中で変えた場合や、手動撮影（ファイル名の先頭が `Manual_`）が混ざる場合にも、撮影時刻と異なる順で表示される。

## 修正内容（What）
### 根本原因
ギャラリーが画像を、撮影時刻ではなくファイル名の文字列順で並べている。ファイル名は「プレフィックス、手動撮影の印、端末の種類、撮影時刻」の順につながっているため、先頭のプレフィックスや端末の種類が違うと、文字列順が撮影の新しい・古いの順にならない。また、セッションの表示順が、そのセッションの中でファイル名の順が最も先頭にくる画像の位置で決まっていた。

### 修正方針
- 画像は、ファイル名ではなく撮影した時刻（保存した時刻）の順に並べる。「新しい順」は撮影が新しいものが先、「古い順」は古いものが先とする。撮影した時刻が同じ画像は、ファイル名の順に並べる。
- セッション同士は、セッション番号の順に並べる。「新しい順」はセッション番号の大きいセッションが上、「古い順」は小さいセッションが上とする。「未分類」は、従来どおり常に末尾に表示する。
- 各セッション・未分類の中の画像も、上記の撮影した時刻の順に並べる。並べ替えたセッション（[session-grouping.md](../session-grouping.md)）の扱い、セッション単位のダウンロードの連番の規則は変えない。

## 受入基準（再発防止・回帰テスト）
1. **再現手順の検証**: 再現手順を実行すると、並び順が「新しい順」のとき、セッション2がセッション1より上に表示されること。「古い順」に切り替えると、セッション1が上になること。
2. **未分類は末尾**: どちらの並び順でも、「未分類」が一番下に表示されること。
3. **セッション内の順序**: 各セッションの中で、「新しい順」は撮影が新しい画像が先、「古い順」は撮影が古い画像が先に並ぶこと。プレフィックスや端末の種類、手動撮影が混ざっていても同じであること。
4. **見出しが1回**: セッションの見出しが、セッションごとに1回だけ表示されること。
5. **回帰**: 並べ替えたセッションの表示、セッション単位のダウンロード（連番）、全選択・個別選択・削除、端末フィルタが従来どおり動作すること。
