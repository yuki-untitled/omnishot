# バグ修正: 「アプリ終了」後のメッセージが、ブラウザのタブ前提の文言のままになっている

## Issue
#LOCAL-011

## 不具合現象と再現手順（Why）
### 発生している現象
[native-window.md](../native-window.md) により、アプリはブラウザのタブではなくネイティブウィンドウで表示されるようになった。しかし、画面の「アプリ終了」ボタンを押した後に表示されるメッセージは「このタブを閉じてもらって大丈夫です」のままで、実態（ウィンドウで動作している）と合っていない。ユーザーは「タブ」を探して迷う。

### 再現手順
1. アプリを起動する
2. 画面の「アプリ終了」ボタンを押し、確認ダイアログで承諾する
3. 期待値・実際の差異
   - 期待値: ネイティブウィンドウの実態に合った文言（「タブ」という語を含まない）が表示される
   - 実際: 「アプリケーションを終了しました。このタブを閉じてもらって大丈夫です。」と表示される

## 修正内容（What）
### 根本原因
- ネイティブウィンドウ化（#LOCAL-005）の際に、画面上の文言の見直しが行われなかった

### 修正方針
- 「アプリ終了」後に表示するメッセージから「タブ」という語を除き、アプリケーションが終了したことのみを伝える文言にする
- 終了時の後始末（撮影データの一時フォルダ削除など）の挙動は変えない

## 受入基準（再発防止・回帰テスト）
1. **文言の検証**: 「アプリ終了」後に表示されるメッセージに「タブ」という語が含まれないこと。
2. **回帰（終了処理）**: 「アプリ終了」ボタンで、従来通り撮影データの一時フォルダ・iOS関連の一時ファイルが削除され、アプリケーションプロセスが終了すること（[native-window.md](../native-window.md) 受入基準2）。
